Arbeitsbereiche

Ein Arbeitsbereich ist eine gespeicherte Momentaufnahme Ihrer beiden Panels: die Ordner, die sie zeigen, jeder geöffnete Tab, welcher Tab auf jeder Seite aktiv ist und welches Panel den Fokus hat. Speichern Sie die Anordnung, die Sie für eine Aufgabe verwenden, ein einziges Mal, und Sie können sie später mit einer einzigen Auswahl vollständig zurückholen. Arbeitsbereiche sind ideal für Konfigurationen pro Projekt, sodass Sie direkt von den Ordnern und Tabs einer Aufgabe zu denen einer anderen springen können, ohne etwas von Hand erneut zu öffnen.

Vorgehen

  1. Richten Sie beide Panels so ein, wie Sie sie haben möchten: öffnen Sie die Ordner, fügen Sie die Tabs hinzu und wählen Sie das Panel, das aktiv sein soll.
  2. Öffnen Sie das Menü Gehe zu und wählen Sie Arbeitsbereich sichern….
  3. Geben Sie einen Namen für den Arbeitsbereich ein und bestätigen Sie. Das aktuelle Layout beider Panels wird unter diesem Namen gespeichert.
  4. Um später zu einem gespeicherten Layout zurückzukehren, öffnen Sie das Menü Gehe zu und wählen Sie Arbeitsbereiche….
  5. Klicken Sie in der Aufklappliste auf den gewünschten Arbeitsbereich. Beide Panels, ihre Tabs und die aktive Seite werden wiederhergestellt.
  6. Um einen Arbeitsbereich zu entfernen, öffnen Sie Arbeitsbereiche…, zeigen Sie auf Löschen und wählen Sie den Namen aus dem Untermenü.

Tastenkürzel

Aktion Kürzel
Aktuelles Layout als Arbeitsbereich sichern Cmd+Ctrl+S

Tipps

  • In der Aufklappliste Arbeitsbereiche… erhalten Ihre ersten neun gespeicherten Arbeitsbereiche die Schnellauswahl-Zifferntasten 1 bis 9, sodass Sie mit einem einzigen Tastendruck wechseln können.
  • Sie können auch aus der Aufklappliste Arbeitsbereiche… heraus einen neuen Arbeitsbereich mit Aktuellen als Arbeitsbereich sichern… speichern, ohne die Liste zu verlassen.
  • Benennen Sie Arbeitsbereiche nach der Arbeit, die sie unterstützen ("Website", "Fotoimport", "Backups"), damit die Liste übersichtlich bleibt.

Hinweise

  • Das Laden eines Arbeitsbereichs ersetzt die Tabs in beiden Panels durch den gespeicherten Satz. Alles, was Sie geöffnet, aber nicht gespeichert hatten, bleibt nicht erhalten, speichern Sie also zuerst Ihr aktuelles Layout, wenn Sie dorthin zurückkehren möchten.
  • Ein Arbeitsbereich zeichnet Ordnerorte und Tabs auf, nicht die darin enthaltenen Dateien. Wenn ein gespeicherter Ordner verschoben oder gelöscht wurde, öffnet sich dieser Tab dort, wo es möglich ist.
