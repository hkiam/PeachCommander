Workspaces

A workspace is a saved snapshot of your two panels: the folders they show, every open tab, which tab is active on each side, and which panel is focused. Save the arrangement you use for a task once, and you can bring it all back with a single choice later. Workspaces are ideal for per-project setups, so you can jump straight from one job's folders and tabs to another's without reopening anything by hand.

How to

  1. Set up both panels the way you want them: open the folders, add the tabs, and select the panel you want active.
  2. Open the Go menu and choose Save Workspace….
  3. Type a name for the workspace and confirm. The current layout of both panels is stored under that name.
  4. To return to a saved layout later, open the Go menu and choose Workspaces….
  5. In the pop-up list, click the workspace you want. Both panels, their tabs, and the active side are restored.
  6. To remove a workspace, open Workspaces…, point at Delete, and choose the name from the submenu.

Shortcuts

Action Shortcut
Save current layout as a workspace Cmd+Ctrl+S

Tips

  • In the Workspaces… pop-up, your first nine saved workspaces get quick-select number keys 1 through 9, so you can switch with a single keystroke.
  • You can also save a new workspace from inside the Workspaces… pop-up with Save Current as Workspace…, without leaving the list.
  • Name workspaces after the work they support ("Website", "Photo import", "Backups") so the list stays easy to scan.

Notes

  • Loading a workspace replaces the tabs in both panels with the saved set. Anything you had open but did not save is not kept, so save your current layout first if you want to come back to it.
  • A workspace records folder locations and tabs, not the files inside them. If a saved folder has been moved or deleted, that tab reopens wherever it can.
