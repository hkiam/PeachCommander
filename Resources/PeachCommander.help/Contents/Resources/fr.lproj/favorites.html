Favoris et liste rapide

Les favoris (la liste rapide de dossiers) sont des raccourcis pratiques vers les dossiers que vous ouvrez en permanence. Au lieu de cliquer sans cesse à travers le même chemin, vous l'enregistrez une fois et y revenez directement depuis un court menu — depuis l'un ou l'autre panneau, à tout moment. Vous pouvez conserver une liste plate ou regrouper des dossiers apparentés dans des sous-menus (par exemple, tous vos dossiers de projets sous un seul intitulé « Projets »).

Ouvrir le menu des favoris

  1. Faites du panneau que vous souhaitez explorer le panneau actif (cliquez dedans).
  2. Appuyez sur Ctrl+D, ou choisissez Aller > Liste rapide de dossiers….
  3. Le menu des favoris apparaît à côté du panneau. Cliquez sur un dossier pour l'y ouvrir.

Vos neuf premiers favoris sont numérotés dans le menu : vous pouvez donc les sélectionner en appuyant sur 1 à 9 dès que le menu est ouvert.

Ajouter le dossier courant

  1. Ouvrez le dossier que vous souhaitez mémoriser dans le panneau actif.
  2. Appuyez sur Ctrl+D pour ouvrir le menu des favoris.
  3. Choisissez Ajouter le dossier courant. Le dossier est ajouté au bas de la liste et est disponible immédiatement.

Organiser vos favoris

  1. Ouvrez le menu des favoris et choisissez Organiser la liste rapide….
  2. Dans la fenêtre qui s'ouvre, modifiez le Titre et le Chemin de chaque favori directement dans le tableau. Double-cliquez sur une cellule pour la modifier.
  3. Faites glisser les lignes pour les réordonner — l'ordre ici est l'ordre dans lequel elles apparaissent dans le menu.
  4. Utilisez les boutons pour ajouter un nouveau favori ou une ligne de séparation.
  5. Pour regrouper des favoris dans un sous-menu, placez une barre oblique inverse dans le titre : un favori intitulé Projets\SiteWeb apparaît sous un sous-menu Projets en tant que SiteWeb. Vous pouvez imbriquer plusieurs niveaux de cette façon.
  6. Fermez la fenêtre pour enregistrer. Vos favoris sont conservés d'un lancement à l'autre.

(Figure : la fenêtre Organiser la liste rapide — modifiez les titres et les chemins, réordonnez les lignes, et utilisez des barres obliques inverses dans un titre pour construire des sous-menus.)

La pastille étoile

Au-dessus de la liste de fichiers de chaque panneau se trouve une petite pastille ★. Cliquez dessus pour ouvrir un menu d'emplacements courants (Départ, Bureau, Téléchargements, etc.) suivi de vos favoris. C'est un moyen rapide d'atteindre un favori sans avoir à changer d'abord de panneau actif — le dossier s'ouvre dans ce panneau. Le même menu comporte une entrée Liste rapide de dossiers… qui ouvre l'organiseur.

Raccourcis

Action Raccourci
Ouvrir le menu des favoris Ctrl+D
Ajouter le dossier courant Ctrl+D, puis Ajouter le dossier courant
Choisir l'un des neuf premiers favoris 1–9 (lorsque le menu est ouvert)

Remarques

  • Un titre composé d'un seul tiret (-) crée une ligne de séparation dans le menu, pratique pour séparer les groupes.
  • Les favoris sont partagés par les deux panneaux — la même liste apparaît où que vous ouvriez le menu.
  • Le menu n'affiche les raccourcis numériques (1–9) que pour les neuf premiers favoris ; les autres sont toujours présents et cliquables, simplement sans numéro.
