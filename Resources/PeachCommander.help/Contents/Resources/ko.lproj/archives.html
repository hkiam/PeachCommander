압축 파일 다루기

Peach Commander는 압축 파일을 폴더처럼 취급합니다. 먼저 디스크에 풀지 않고도 ZIP, TAR 또는 기타 지원되는 압축 파일 안으로 들어가 내용을 탐색하고 파일을 꺼낼 수 있습니다. 압축 파일을 만들려면 Pack 명령이 선택 항목을 ZIP, 7z, TAR 또는 기타 형식으로 묶으며, 선택적 암호화와 분할 볼륨을 지원합니다. 이는 보낼 파일을 묶거나, 저장을 위해 폴더를 줄이거나, 추출을 확정하기 전에 다운로드 내부를 살짝 들여다볼 때 편리합니다.

압축 파일을 폴더처럼 탐색

  1. 패널에서 커서를 압축 파일(예: .zip 또는 .tar.gz)로 이동합니다.
  2. 폴더를 열 듯이 Enter 또는 Ctrl+PageDown을 눌러 안으로 들어갑니다.
  3. 내용을 일반적으로 탐색합니다. Backspace 또는 Ctrl+PageUp을 누르면 위로 올라가 압축 파일을 벗어납니다.
  4. 파일을 꺼내려면 파일을 선택하고 다른 패널로 복사(F5)합니다.

(그림: 일반 폴더 목록처럼 표시된, 열린 압축 파일. 파일을 꺼낼 준비가 되어 있습니다.)

ZIP, TAR, gzip으로 압축된 TAR은 직접 읽습니다. CPIO, ISO, CAB, LZH, XAR, PAX 같은 다른 형식은 기본 제공 시스템 도구를 통해 읽습니다. 암호화된 ZIP 압축 파일(고전 방식과 AES 모두)은 암호를 입력하면 열 수 있습니다.

파일을 새 압축 파일로 묶기

  1. 활성 패널에서 포함할 파일과 폴더를 선택합니다.
  2. 파일 ▸ Pack…을 선택하거나 Alt+F5를 누릅니다. (묶은 다음 원본을 삭제하려면 Alt+Shift+F5를 사용합니다.)
  3. 대화상자에서 압축 파일 형식(ZIP, 7z, TAR, tar.gz, bzip2, xz, RAR), 압축 수준, 저장 위치를 선택합니다.
  4. 선택적으로 AES-256 암호화를 켜고 암호를 설정하거나, 압축 파일을 고정 크기 볼륨으로 분할합니다.
  5. 확인하여 압축 파일을 만듭니다.

(그림: 형식을 선택하고 암호화 및 분할 볼륨 옵션을 설정하는 Pack 대화상자.)

압축 파일 풀기 또는 검사하기

  1. 추출할 압축 파일을 활성 패널에, 대상 폴더를 다른 패널에 놓습니다.
  2. 파일 ▸ Unpack…을 선택하거나 Alt+F9를 누른 다음 대상을 확인합니다.
  3. 추출하지 않고 압축 파일의 손상 여부를 확인하려면 파일 ▸ Test Archive를 선택합니다.

ZIP을 제자리에서 편집

기존 ZIP을 풀지 않고도 그 안의 파일을 추가하거나 제거할 수 있습니다. ZIP을 폴더로 연 다음, 평소처럼 파일을 복사해 넣거나 삭제하면 변경 내용이 곧바로 압축 파일에 기록됩니다.

단축키

작업 단축키
커서 아래의 압축 파일로 들어가기 Enter 또는 Ctrl+PageDown
압축 파일 벗어나기(위로 가기) Backspace 또는 Ctrl+PageUp
묶기(Pack) Alt+F5
묶고 원본 삭제 Alt+Shift+F5
풀기(Unpack) Alt+F9

참고

  • 7z, xz, bzip2, RAR로 묶는 것은 외부 도구에 의존합니다. 특히 RAR은 독점 RAR 프로그램이 설치되어 있어야 합니다. 없으면 해당 형식을 사용할 수 없습니다.
  • ZIP을 제자리에서 편집하면 압축 파일 전체가 다시 기록되므로, 그 안의 파일 수정 타임스탬프는 보존되지 않습니다.
  • 개별 구성원이 매우 큰 경우 추출 시 512 MiB로 제한됩니다. 추출은 실행 중에 취소할 수 있습니다.
  • ZIP64 압축 파일도 다른 것과 똑같이 열리므로 항목이 65,535개를 넘거나 4 GB보다 큰 압축 파일도 평소처럼 살펴볼 수 있습니다. 위에 적은 개별 파일 압축 해제 한도는 그대로 적용됩니다.
