새 폴더 및 파일

파일을 정리할 때, 파일을 넣을 새 위치나 시작할 새 문서가 필요한 경우가 많습니다. Peach Commander를 사용하면 Finder로 전환하지 않고도 작업 중인 패널에서 직접 새 폴더나 새 텍스트 파일을 만들 수 있습니다. 새 항목은 활성 패널에 현재 표시된 폴더에 만들어집니다.

새 폴더 만들기

  1. 새 폴더가 나타나기를 원하는 패널을 클릭하여 활성 패널로 만듭니다.
  2. F7을 누릅니다.
  3. 나타나는 상자에 이름을 입력합니다.
  4. Return을 누릅니다(또는 OK를 클릭합니다). 새 폴더가 패널에 나타나 사용할 준비가 됩니다.

한 단계로 폴더 하나를 만드는 것 이상을 할 수 있습니다.

  • 중첩된 폴더를 한 번에. a/b/c처럼 슬래시가 있는 경로를 입력하면 b를 담은 a, 그 안에 c를 담은 폴더를 만듭니다. 아직 존재하지 않는 단계는 자동으로 만들어집니다.
  • 여러 폴더를 한 번에. d1|d2처럼 이름을 세로 막대로 구분하면 d1과 d2를 나란히 만듭니다. 두 방식을 결합할 수도 있습니다(예: reports/2026|archive).

새 텍스트 파일 만들기

  1. 새 파일이 나타나기를 원하는 패널을 클릭합니다.
  2. Shift+F4를 누릅니다.
  3. 확장자를 포함하여 파일 이름을 입력합니다(예: notes.txt).
  4. Return을 누릅니다. 빈 파일이 만들어지고 편집기에서 열리므로 바로 입력을 시작할 수 있습니다.

파일은 Peach Commander가 해당 종류의 파일에 사용하도록 설정된 편집기에서 열립니다. 편집이 어떻게 동작하는지는 파일 열기 및 보기를 참조하십시오.

단축키

작업 키
새 폴더 F7
새 텍스트 파일 Shift+F4

참고

  • macOS에서 폴더나 파일 이름은 거의 모든 문자를 포함할 수 있습니다. 단일 이름에서는 슬래시 /(중첩된 폴더의 경로 구분자로 사용됨)와 몇 가지 예약된 문자만 허용되지 않습니다.
  • 이름에 콜론 :을 사용하는 것은 가능하지만 Finder에서 혼란스러워 보일 수 있으므로 피하는 것이 좋습니다.
  • 같은 이름의 폴더가 이미 존재하면 Peach Commander는 기존 폴더를 그대로 유지합니다. 아무것도 덮어쓰지 않습니다.
