파일 및 폴더 열기

Peach Commander는 어느 쪽 패널에서든 파일과 폴더를 바로 열며, Finder에서 이미 사용하던 것과 동일한 앱과 시스템 기능을 사용합니다. 키 하나로 커서 아래 항목을 기본 앱에서 열거나, 마우스 오른쪽 버튼을 클릭해 전체 동작 메뉴를 열 수 있습니다 — 다른 앱으로 열기, Finder에서 항목 보기, 공유, 또는 현재 위치에서 바로 터미널 창 열기.

항목 열기

  1. 패널에서 파일이나 폴더를 클릭해 커서를 놓습니다(강조 표시된 행).
  2. Enter를 누릅니다(또는 두 번 클릭). - 폴더는 같은 패널에서 열립니다. - 파일은 macOS 기본 앱에서 열립니다 — Finder가 사용하는 것과 같은 앱입니다. - 압축 파일(예: .zip)은 폴더처럼 열려 내부를 탐색할 수 있습니다.

(그림: 아무 항목에나 커서를 놓고 Enter를 눌러 엽니다.)

다른 앱으로 열기, Finder에서 보기, 공유

파일을 마우스 오른쪽 버튼으로 클릭하거나(또는 Shift+F10) 항목 메뉴를 연 다음 선택합니다:

  • 열기 또는 기본 앱에서 열기 — Enter와 동일하게 파일을 엽니다.
  • 다음으로 열기 — 이 파일을 열 수 있는 설치된 앱을 고르거나 기타…를 선택해 직접 찾습니다.
  • Quick Look — 앱을 열지 않고 파일을 미리 봅니다.
  • Finder에서 보기 — Finder 창에서 파일을 선택된 상태로 표시합니다.
  • 공유… — macOS 공유 시트로 파일을 보냅니다.

이 메뉴에는 선택한 파일에 대한 표준 macOS 서비스도 통합되며, 익숙한 Finder 색상 태그를 적용할 수 있도록 태그가 추가됩니다.

현재 폴더에서 터미널 열기

파일 또는 명령 메뉴에서 여기서 터미널 열기(Cmd+Option+T)를 선택하면 활성 패널의 폴더를 가리키는 터미널 창이 열립니다.

단축키

동작 키
커서 아래 항목 열기 Enter
파일 보기(뷰어) F3
파일 편집 F4
Quick Look 미리 보기 Cmd+Y
정보 가져오기 / 속성 Option+Enter
항목 메뉴 열기 Shift+F10 또는 오른쪽 클릭
여기서 터미널 열기 Cmd+Option+T

참고

  • "기본 앱"은 macOS가 해당 파일 형식에 사용하도록 설정된 앱을 뜻합니다. Finder에서와 똑같이 파일의 정보 가져오기 패널에서 변경할 수 있습니다.
  • Finder에서 보기, 공유…, 다음으로 열기 ▸ 기타…는 Mac 디스크에 있는 항목에만 적용됩니다. 압축 파일 내부나 원격(FTP/SFTP) 연결의 항목에는 사용할 수 없습니다.
  • 실행 중인 프로세스를 오른쪽 클릭하면(프로세스 보기에서) 파일 동작 대신 더 짧은 프로세스 전용 메뉴가 표시됩니다.
