탭

각 패널은 여러 폴더를 탭으로 동시에 담을 수 있어, 앞뒤로 이동하는 대신 자주 쓰는 위치를 클릭 한 번 거리에 둘 수 있습니다. 탭은 하나의 패널에 속합니다. 왼쪽과 오른쪽 패널은 각자 자신의 탭 줄을 유지하며, 탭을 전환하거나 닫는 것은 활성 패널에만 영향을 줍니다. 파일 목록 위에 작은 탭 막대가 나타나 열린 탭마다 칩 하나와 끝에 "+" 버튼을 표시합니다.

탭 다루기

  1. 패널을 클릭해 활성화합니다. 새 탭은 항상 활성 패널에서 열립니다.
  2. 보기 > 새 탭을 선택하거나 Cmd+T를 눌러 현재 폴더로 새 탭을 엽니다. 탭 막대 끝의 "+" 버튼을 클릭해도 됩니다.
  3. 탭 칩을 클릭해 전환하거나, 다음 탭은 Cmd+}, 이전 탭은 Cmd+{를 누릅니다.
  4. 현재 탭을 닫으려면 보기 > 탭 닫기를 선택하거나 Cmd+W를 누릅니다. 탭 칩을 가운데 버튼으로 클릭해도 닫힙니다. 보기 > 모든 탭 닫기를 선택하면 현재 탭만 남깁니다.

(그림: 탭 막대는 파일 목록 위에 있으며, 탭마다 칩 하나와 새 탭을 여는 "+" 버튼이 있습니다.)

폴더를 새 탭에서 열기

  1. 파일 목록에서 폴더로 커서를 옮깁니다.
  2. 보기 > 새 탭에서 폴더 열기(Cmd+Shift+T)를 선택하면 같은 패널의 새 탭에서 그 폴더가 열립니다.
  3. 현재 탭을 벗어나지 않고 탭을 열려면 보기 > 백그라운드에서 새 탭을 선택합니다.

탭 잠그기

탭을 잠그면 해당 폴더에 고정됩니다. 탭을 선택한 다음 보기 > 탭 잠금을 선택하면 탭 칩에 작은 자물쇠 아이콘이 나타납니다. 탭이 잠겨 있으면 다른 폴더로 이동할 때 잠긴 탭을 바꾸지 않고 새 탭에서 그 폴더를 열어, 고정한 위치가 그대로 유지됩니다. 메뉴 항목을 다시 선택하면 잠금이 해제됩니다.

단축키

동작 단축키
새 탭 Cmd+T
백그라운드에서 새 탭 보기 > 백그라운드에서 새 탭
커서 아래 폴더를 새 탭에서 열기 Cmd+Shift+T
현재 탭 닫기 Cmd+W
다음 탭 Cmd+}
이전 탭 Cmd+{
탭 잠금 / 잠금 해제 보기 > 탭 잠금

팁

  • 탭 칩을 오른쪽 클릭하면 해당 탭 복제나 닫기 같은 빠른 동작을 사용할 수 있습니다.
  • 탭은 패널별로 유지됩니다. 작업 폴더와 대상 폴더를 나란히 두고 위치를 잃지 않은 채 서로 전환하는 데 활용하세요.
  • 잠금은 자주 돌아오는 폴더에 유용합니다. 다른 곳을 탐색하고도 그 탭에서 변하지 않은 폴더를 다시 찾을 수 있습니다.
