빠른 검색 및 필터

폴더에 수백 개의 항목이 있어도 스크롤할 필요는 거의 없습니다. Peach Commander에서는 이름을 입력해 파일로 바로 이동하고(빠른 검색), 목록을 원하는 항목만 남도록 줄이며(빠른 필터), macOS가 평소 숨기는 점 파일(dotfile)을 표시하거나 숨길 수 있습니다. 세 가지 모두 대화 상자 없이 활성 패널 안에서 동작합니다.

입력으로 파일 찾아가기(빠른 검색)

  1. 파일 패널을 클릭해 활성화합니다.
  2. 이름의 앞부분을 입력하기 시작합니다. 커서가 일치하는 첫 항목으로 이동합니다.
  3. 계속 입력해 일치를 좁히거나, 같은 글자를 다시 눌러 그 글자로 시작하는 항목들을 순환합니다.
  4. 입력한 텍스트는 잠시 후 지워지므로 언제든 새 검색을 시작할 수 있습니다.

기본적으로 일반 글자는 명령줄로 가고 빠른 검색은 Ctrl+Option+글자로 실행됩니다(고전 방식). 설정에서 빠른 검색이 일반 입력에 반응하도록 바꾸거나 끌 수 있습니다.

목록 필터링(빠른 필터)

  1. 활성 패널에서 Ctrl+S를 눌러 빠른 필터를 켭니다.
  2. 필터 마스크를 입력합니다. 입력하는 대로 패널이 일치하는 항목으로 실시간으로 좁혀집니다.
  3. Esc를 누르면 필터가 지워지고 모두 다시 표시됩니다.

필터는 여러 종류의 마스크를 받습니다:

  • 일반 텍스트는 입력한 내용을 이름 어디에든 포함하는 모든 항목과 일치합니다(예: report는 이름 어딘가에 "report"가 있는 모든 항목을 표시).
  • 와일드카드는 *(임의의 문자)와 ?(문자 하나)를 사용합니다. 여러 마스크는 세미콜론으로 구분하고 제외는 세로 막대 뒤에 추가합니다. 예: *.jpg;*.png|*thumb*는 이미지를 표시하되 썸네일은 숨깁니다.
  • Finder 태그는 태그 색으로 필터링합니다. tag:red(또는 #red)를 입력하면 빨간 태그 항목만, tag:만 입력하면 태그가 있는 모든 항목을 표시합니다.

숨김 파일 표시

Ctrl+H를 누르거나 보기 메뉴의 명령을 선택해 숨김 항목(점으로 시작하는 이름과 시스템 숨김 파일)을 켜고 끕니다. 이 설정은 활성 패널에 적용되며 세션 간에 기억됩니다.

단축키

동작 단축키
빠른 검색(고전 방식) Ctrl+Option+글자
빠른 필터 켜기/끄기 Ctrl+S
필터 지우기 / 취소 Esc
숨김 파일 표시/숨기기 Ctrl+H

참고

  • 빠른 검색은 커서만 이동시키지만, 빠른 필터는 실제로 나열되는 항목을 바꿉니다. 부분 집합에 대해 작업하려면(예: 일치 항목만 선택하거나 복사) 필터를 사용하세요.
  • 필터와 숨김 파일 설정은 패널별이므로 양쪽에서 서로 다른 것을 동시에 표시할 수 있습니다.
  • 빠른 검색은 이름을 처음부터 일치시키고, 빠른 필터의 일반 텍스트 모드는 이름 어디에서든 일치시킵니다. 필터도 동일하게 동작하게 하려면 *text* 같은 와일드카드를 쓰세요.
