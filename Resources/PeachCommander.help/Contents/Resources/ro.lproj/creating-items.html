Foldere și fișiere noi

Când organizați fișiere, aveți deseori nevoie de un loc nou în care să le puneți sau de un document nou de la care să porniți. Peach Commander vă permite să creați un folder nou sau un fișier text nou direct în panoul în care lucrați, fără a trece la Finder. Elementele noi sunt create în folderul afișat curent în panoul activ.

Crearea unui folder nou

  1. Faceți clic pe panoul în care doriți să apară noul folder, astfel încât să devină panoul activ.
  2. Apăsați F7.
  3. Tastați un nume în caseta care apare.
  4. Apăsați Return (sau faceți clic pe OK). Noul folder apare în panou, gata de folosit.

Puteți face mai mult decât să creați un singur folder într-un singur pas:

  • Foldere imbricate dintr-o dată. Tastați o cale cu bare oblice, cum ar fi a/b/c, pentru a crea un folder a care conține b care conține c. Orice niveluri care nu există încă sunt create pentru dumneavoastră.
  • Mai multe foldere deodată. Separați numele cu o bară verticală, cum ar fi d1|d2, pentru a crea atât d1, cât și d2 alăturate. Puteți combina ambele stiluri, de exemplu reports/2026|archive.

Crearea unui fișier text nou

  1. Faceți clic pe panoul în care doriți să apară noul fișier.
  2. Apăsați Shift+F4.
  3. Tastați un nume pentru fișier, inclusiv extensia sa (de exemplu notes.txt).
  4. Apăsați Return. Fișierul gol este creat și se deschide în editorul dumneavoastră, astfel încât să puteți începe imediat să tastați.

Fișierul se deschide în editorul pe care Peach Commander este setat să îl folosească pentru acel tip de fișier. Consultați Deschiderea și vizualizarea fișierelor pentru modul în care funcționează editarea.

Scurtături

Acțiune Tastă
Folder nou F7
Fișier text nou Shift+F4

Note

  • Pe macOS, un nume de folder sau de fișier poate conține aproape orice caracter. Doar bara oblică / (folosită ca separator de cale pentru foldere imbricate) și câteva caractere rezervate nu sunt permise într-un singur nume.
  • Folosirea unui două puncte : într-un nume este posibilă, dar poate arăta derutant în Finder, așa că este bine să o evitați.
  • Dacă un folder cu același nume există deja, Peach Commander pur și simplu îl păstrează pe cel existent — nimic nu este suprascris.
