File

Fiecare panou poate ține mai multe foldere deodată ca file, astfel încât puteți avea locurile pe care le folosiți des la doar un clic distanță în loc să navigați înainte și înapoi. Filele aparțin unui singur panou: panoul stâng și cel drept țin fiecare propriul rând de file, iar comutarea sau închiderea unei file afectează doar panoul activ. O mică bară de file apare deasupra listei de fișiere, cu o pastilă per filă deschisă plus un buton „+" de încheiere.

Lucrul cu filele

  1. Faceți clic pe un panou pentru a-l face activ. Filele noi se deschid întotdeauna în panoul activ.
  2. Alegeți Vizualizare > Filă nouă, sau apăsați Cmd+T, pentru a deschide o filă nouă pe folderul curent. Puteți de asemenea face clic pe butonul „+" de la capătul barei de file.
  3. Faceți clic pe o pastilă de filă pentru a comuta la ea, sau apăsați Cmd+} pentru fila următoare și Cmd+{ pentru cea anterioară.
  4. Pentru a închide fila curentă, alegeți Vizualizare > Închide fila sau apăsați Cmd+W. Puteți de asemenea face clic cu butonul din mijloc pe o pastilă de filă pentru a o închide. Alegeți Vizualizare > Închide toate filele pentru a le elimina pe toate în afară de cea curentă.

(Figura: bara de file se află deasupra listei de fișiere, cu o pastilă per filă și un buton „+" pentru a deschide una nouă.)

Deschideți un folder într-o filă nouă

  1. Mutați cursorul pe un folder în lista de fișiere.
  2. Alegeți Vizualizare > Deschide folderul într-o filă nouă (Cmd+Shift+T) pentru a deschide acel folder într-o filă nouă în același panou.
  3. Pentru a deschide o filă fără a părăsi cea curentă, alegeți Vizualizare > Filă nouă în fundal.

Blocarea unei file

Blocarea unei file o ține fixată la folderul ei. Marcați fila și alegeți Vizualizare > Blochează fila. O mică pictogramă de lacăt apare pe pastila filei. Când o filă este blocată, navigarea la un alt folder îl deschide într-o filă nouă în loc să o schimbe pe cea blocată, astfel încât locul dvs. fixat rămâne. Alegeți din nou elementul de meniu pentru a o debloca.

Comenzi rapide

Acțiune Comandă rapidă
Filă nouă Cmd+T
Filă nouă în fundal Vizualizare > Filă nouă în fundal
Deschide folderul de sub cursor într-o filă nouă Cmd+Shift+T
Închide fila curentă Cmd+W
Fila următoare Cmd+}
Fila anterioară Cmd+{
Blochează/deblochează fila Vizualizare > Blochează fila

Sfaturi

  • Faceți clic dreapta pe o pastilă de filă pentru acțiuni rapide precum duplicarea sau închiderea acelei file.
  • Filele sunt per panou. Folosiți-le pentru a ține un folder de lucru și un folder de destinație unul lângă altul, apoi comutați între ele fără a vă pierde locul.
  • Blocarea este utilă pentru un folder la care reveniți des: puteți naviga departe de el și totuși îl găsiți, neschimbat, pe fila lui.
