Новые папки и файлы

Когда вы упорядочиваете файлы, часто нужно новое место, куда их поместить, или новый документ, с которого можно начать. Peach Commander позволяет создать новую папку или новый текстовый файл прямо в панели, с которой вы работаете, не переключаясь в Finder. Новые элементы создаются в папке, показанной в данный момент в активной панели.

Создание новой папки

  1. Щёлкните панель, где хотите, чтобы появилась новая папка, чтобы она стала активной.
  2. Нажмите F7.
  3. Введите имя в появившемся поле.
  4. Нажмите Return (или щёлкните OK). Новая папка появится в панели, готовая к использованию.

Вы можете за один шаг сделать больше, чем создать одну папку:

  • Вложенные папки за один раз. Введите путь с косыми чертами, например a/b/c, чтобы создать папку a, содержащую b, содержащую c. Любые ещё не существующие уровни создаются за вас.
  • Несколько папок сразу. Разделяйте имена вертикальной чертой, например d1|d2, чтобы создать d1 и d2 рядом. Вы можете комбинировать оба стиля, например reports/2026|archive.

Создание нового текстового файла

  1. Щёлкните панель, где хотите, чтобы появился новый файл.
  2. Нажмите Shift+F4.
  3. Введите имя файла, включая его расширение (например, notes.txt).
  4. Нажмите Return. Пустой файл создаётся и открывается в вашем редакторе, так что вы можете сразу начать печатать.

Файл открывается в том редакторе, который Peach Commander настроен использовать для файлов такого рода. См. Открытие и просмотр файлов о том, как работает редактирование.

Сочетания клавиш

Действие Клавиша
Новая папка F7
Новый текстовый файл Shift+F4

Примечания

  • В macOS имя папки или файла может содержать почти любой символ. В отдельном имени не допускаются только косая черта / (используемая как разделитель пути для вложенных папок) и несколько зарезервированных символов.
  • Использование двоеточия : в имени возможно, но может выглядеть запутанно в Finder, поэтому его лучше избегать.
  • Если папка с таким же именем уже существует, Peach Commander просто сохраняет существующую — ничего не перезаписывается.
