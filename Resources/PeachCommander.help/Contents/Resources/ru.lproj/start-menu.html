Меню «Пуск» и пользовательские команды

Меню Пуск — это ваше собственное личное меню, расположенное в строке меню рядом с Файл, Правка и остальными. Оно содержит команды, которые вы определяете сами, поэтому действия, к которым вы обращаетесь чаще всего, всегда в одном щелчке. В традиции классических двухпанельных файловых менеджеров каждая запись может запускать встроенную команду, запускать внешнюю программу или приложение либо сразу переходить к папке. Peach Commander поставляется с пустым меню «Пуск», готовым к тому, чтобы вы его заполнили.

Как добавить свои команды

  1. Выберите Пуск > Изменить меню «Пуск»…. Peach Commander открывает ваш файл пользовательских команд (создавая его с закомментированным примером в первый раз).
  2. Добавьте по одной секции на команду. Каждая секция начинается с имени в квадратных скобках, затем несколько простых ключей: - cmd — что запускать: путь к программе, приложение, встроенную команду cm_ или другую из ваших команд. - param — параметры, передаваемые программе. Заполнители подставляются при запуске команды: %P (папка-источник), %N (текущий файл), %T (папка другой панели), %M (файл другой панели), %S (выделенные файлы). - path — папка, в которой начинать (по умолчанию текущая папка). - menu — заголовок, показываемый в меню «Пуск». - key — необязательное сочетание, например C+S+B.
  3. Сохраните файл. Меню «Пуск» обновляется само в следующий раз, когда Peach Commander становится активным, поэтому ваши новые записи появляются сразу.

Советы

  • Чтобы открыть текущую папку в Терминале, задайте cmd как open, param как -a Terminal %P, а menu как Открыть Терминал здесь.
  • Направьте cmd на команду cm_, чтобы дать встроенному действию собственную запись меню «Пуск» и сочетание клавиш.
  • Порядок в файле — это порядок в меню, поэтому ставьте самые используемые команды наверх.

Примечания

  • Вы также можете заменить всю строку меню своей собственной. Выберите Конфигурация > Изменить файл меню…, чтобы открыть файл меню, засеянный из текущего, полностью локализованного встроенного меню; редактируйте его свободно, и ваши изменения применятся в следующий раз, когда приложение будет активировано. Удалите файл, чтобы восстановить стандартную строку меню.
