Tangentbord och kortkommandon

Peach Commander är byggt för att styras från tangentbordet. Det levereras med två färdiga kortkommandoscheman och låter dig binda om vilket kommando som helst till de tangenter du föredrar. Om du kommer från en klassisk tvåpanelsfilhanterare kan du behålla tangenterna du redan kan; om du hellre vill använda välbekanta Mac-kombinationer, byt till macOS-schemat med ett klick. En sökbar kommandobläddrare låter dig upptäcka allt appen kan göra och köra vilket kommando som helst efter namn.

Byt tangentbordsschema

  1. Öppna Inställningar (Cmd+, eller Konfiguration > Inställningar…) och välj sidan Tangentbord.
  2. Välj ett schema i menyn Schema: - Total Commander (klassisk) (standard) behåller de traditionella tangenterna, med Ctrl-baserade kombinationer såsom Ctrl+R för att uppdatera en panel. - macOS mappar samma åtgärder till välbekanta Mac-tangenter där det är rimligt, till exempel Cmd+C för att kopiera filer och Cmd+F för att söka.
  3. Ändringen träder i kraft omedelbart över menyerna och kortkommandofältet. Redigera kortkommandon… finns direkt nedanför, eftersom enskilda ombindningar läggs ovanpå det schema du har valt.

Anpassa kortkommandon

  1. Välj Konfiguration > Redigera kortkommandon…, eller klicka på Redigera kortkommandon… på sidan Tangentbord i Inställningar.
  2. Hitta ett kommando med hjälp av sökfältet, och markera sedan dess rad.
  3. Klicka på Spela in… och tryck på tangentkombinationen du vill ha. Den tilldelas direkt.
  4. Om den kombinationen redan användes av ett annat kommando talar en notis om vilket kommando den togs från.
  5. Använd Rensa för att ta bort ett kommandos kortkommando, eller Återställ standard för att förkasta alla dina ändringar och återgå till schemats ursprungliga tangenter.

(Figur: Sök efter ett kommando, och använd sedan Spela in, Rensa eller Återställ standard för att ändra dess kortkommando.)

Bläddra bland alla kommandon

  1. Välj Konfiguration > Kommandobläddrare….
  2. Skriv i sökfältet för att filtrera efter namn, kategori eller beskrivning.
  3. Dubbelklicka på ett kommando, eller markera det och klicka på Kör, för att utföra det på den aktiva panelen.

(Figur: Varje kommando i en sökbar lista, med en kort beskrivning av vart och ett.)

Anteckningar

  • Dina egna kortkommandon sparas automatiskt och läggs ovanpå det aktiva schemat. Att byta schema behåller dina personliga åsidosättningar.
  • Kommandon som inte är tillgängliga i den aktuella kontexten visas nedtonade både i redigeraren för kortkommandon och i kommandobläddraren.
  • För att använda funktionstangenterna (F1–F12) direkt, slå på Använd F1-, F2- osv. tangenter som standardfunktionstangenter i Systeminställningar > Tangentbord. Annars, håll ned tangenten Fn tillsammans med funktionstangenten.
