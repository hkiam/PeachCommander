Peach Commander is built for the keyboard: almost everything you do with the mouse has a key for it. This page groups the default shortcuts by task so you can find the one you need at a glance. Keys shown here are the default **TC Classic** scheme (the one long-time Total Commander users expect). If you prefer Mac-style keys, switch to the **macOS Native** scheme in the Configuration menu, where the same actions move to Command-key combinations (for example Cmd+C to copy, Cmd+F to search). You can also override any individual key.

## Function keys

Many core actions live on the function keys. If pressing F5 changes your volume instead of copying, turn on "Use F1, F2, etc. keys as standard function keys" in System Settings, or hold Fn while pressing the key.

| Key | Action |
|---|---|
| F1 | Open Help |
| F2 | Refresh the active panel |
| F3 | View the file under the cursor |
| F4 | Edit the file under the cursor |
| F5 | Copy the selection to the other panel |
| F6 | Move or rename to the other panel |
| F7 | Create a new folder |
| F8 or Delete | Delete (move to Trash) |
| Shift+F5 | Copy within the same folder |
| Shift+F6 | Rename in place |
| Shift+F8 | Delete permanently (skip Trash) |

## Navigation

| Key | Action |
|---|---|
| Tab | Switch the active panel |
| Enter | Open the folder, archive, or file under the cursor |
| Backspace | Go to the parent folder |
| Ctrl+PageUp | Go to the parent folder |
| Ctrl+PageDown | Open the folder or archive under the cursor |
| Alt+Left / Alt+Right | Go back / forward in history |
| Alt+Down | Show the history list |
| Ctrl+\ | Go to the root of the volume |
| Ctrl+D | Open the favorites (directory hotlist) |

## Selection

| Key | Action |
|---|---|
| Insert | Toggle selection and move down |
| Space | Toggle selection (and calculate folder size) |
| Num + | Select by mask |
| Num - | Unselect by mask |
| Num * | Invert the selection |
| Ctrl+Num + / Ctrl+Num - | Select all / select none |
| Ctrl+A | Select all |
| Alt+Num + | Select all files with the same extension |
| Num / | Restore the previous selection |

## File operations

| Key | Action |
|---|---|
| F5 | Copy |
| F6 | Move or rename |
| F7 | New folder |
| F8 / Delete | Delete to Trash |
| Ctrl+M | Multi-rename tool |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste files |
| Ctrl+L | Calculate the size of the selection |
| Alt+Enter | Show info and properties |

## View

| Key | Action |
|---|---|
| Ctrl+F1 | Brief view |
| Ctrl+F2 | Full (details) view |
| Ctrl+Shift+F1 | Thumbnail view |
| Ctrl+F8 | Tree view in the panel |
| Ctrl+F3 / F4 / F5 / F6 | Sort by name / extension / size / date |
| Ctrl+H | Show or hide hidden files |
| Ctrl+Q | Toggle the Quick View panel |

## Search

| Key | Action |
|---|---|
| Alt+F7 | Find files |
| Ctrl+S | Quick filter (narrow the visible files) |
| Ctrl+B | Branch view (flatten all subfolders) |

## Network

| Key | Action |
|---|---|
| Ctrl+F | Open the connection manager |
| Ctrl+N | New connection |
| Ctrl+Shift+F | Disconnect |

## Tabs

| Key | Action |
|---|---|
| Ctrl+T | New tab |
| Ctrl+Shift+T | New tab in the background |
| Ctrl+W or Ctrl+F4 | Close the current tab |
| Ctrl+Shift+W | Close all tabs |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous tab |

## Notes

- A few TC Classic keys clash with macOS system shortcuts. Ctrl+Left, Ctrl+Right, Ctrl+Up, and Ctrl+Down are used by Mission Control and Spaces; if they don't work in Peach Commander, adjust them in System Settings or remap them in the Configuration menu.
- The macOS Native scheme moves common actions to the Command key while keeping the function-key actions the same. Switch schemes, or change any single key, from the Configuration menu.
- Press Esc to cancel a dialog, clear the command line, or close the Quick View panel.
