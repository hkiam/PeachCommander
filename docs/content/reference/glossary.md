_Generated from `docs/metadata/terminology.yml`. These are the canonical terms used throughout the documentation._

**active panel**
: The panel that currently has the cursor and receives keyboard input; most operations use it as the source.

**button bar**
: The customizable toolbar of command buttons; supports nested sub-bars.

**command**
: A named action (shown in the command browser) that can be run from a menu, the button bar, a shortcut or the command line.

**dock**
: The strip across the bottom of the main window that hosts plugin views needing width — a terminal, a build log, a REPL. Not macOS's own Dock, and not a panel: "panel" is reserved for the two file views, so what the dock holds is a view.
  <br>*(not: bottom panel, bottombar)*

**drive bar**
: The strip above each panel listing mounted volumes and their free space.

**editor**
: The built-in text/code editor (F4) for changing a file's contents.

**favorite**
: A saved folder shortcut in the directory hotlist, reachable from the favorites menu or the star chip.
  <br>*(not: bookmark)*

**function-key bar**
: The row of F3-F8 buttons along the bottom of the window (View, Edit, Copy, Move, New Folder, Delete).

**panel**
: One of the two side-by-side file views in the main window.
  <br>*(not: pane)*

**path bar**
: The editable breadcrumb above each panel showing the current folder as clickable segments.

**plugin**
: An add-on bundle that extends Peach Commander with new archive formats, file systems, viewers, columns or commands.

**Quick Look**
: macOS's own preview panel (Cmd+Y), separate from the in-panel Quick View.

**Quick View**
: A live preview of the file under the cursor, shown inside the opposite panel (Ctrl+Q).

**tab**
: A saved folder location within a panel; each panel can hold several tabs.

**viewer**
: The built-in file viewer (F3) that displays a file as text, code, hex, image or media without changing it.

**workspace**
: A saved arrangement of panel folders, tabs and layout that can be restored by name.
