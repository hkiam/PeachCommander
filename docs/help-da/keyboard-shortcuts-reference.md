Peach Commander er bygget til tastaturet: næsten alt, du gør med musen, har en tast. Denne side grupperer standardgenvejene efter opgave, så du kan finde den, du har brug for, med et blik. Tasterne vist her er standardskemaet **TC Classic** (det, mangeårige Total Commander-brugere forventer). Hvis du foretrækker Mac-tastar, skift til **macOS Native**-skemaet i Konfiguration-menuen, hvor de samme handlinger flyttes til Command-tastkombinationer (for eksempel Cmd+C for at kopiere, Cmd+F for at søge). Du kan også tilsidesætte enhver enkelt tast.

## Funktionstaster

Mange kernehandlinger bor på funktionstasterne. Hvis et tryk på F5 ændrer din lydstyrke i stedet for at kopiere, slå "Brug F1-, F2- osv.-tasterne som standardfunktionstaster" til i Systemindstillinger, eller hold Fn nede, mens du trykker på tasten.

| Tast | Handling |
|---|---|
| F1 | Åbn Hjælp |
| F2 | Opdater det aktive panel |
| F3 | Vis filen under markøren |
| F4 | Rediger filen under markøren |
| F5 | Kopier markeringen til det andet panel |
| F6 | Flyt eller omdøb til det andet panel |
| F7 | Opret en ny mappe |
| F8 eller Delete | Slet (flyt til papirkurv) |
| Shift+F5 | Kopier i samme mappe |
| Shift+F6 | Omdøb på stedet |
| Shift+F8 | Slet permanent (spring papirkurv over) |

## Navigation

| Tast | Handling |
|---|---|
| Tab | Skift det aktive panel |
| Enter | Åbn mappen, arkivet eller filen under markøren |
| Backspace | Gå til den overordnede mappe |
| Ctrl+PageUp | Gå til den overordnede mappe |
| Ctrl+PageDown | Åbn mappen eller arkivet under markøren |
| Alt+Venstre / Alt+Højre | Gå tilbage / frem i historik |
| Alt+Ned | Vis historiklisten |
| Ctrl+\ | Gå til roden af diskområdet |
| Ctrl+D | Åbn favoritterne (mappehurtiglisten) |

## Markering

| Tast | Handling |
|---|---|
| Insert | Skift markering og gå ned |
| Mellemrum | Skift markering (og beregn mappestørrelse) |
| Num + | Vælg efter maske |
| Num - | Fravælg efter maske |
| Num * | Inverter markeringen |
| Ctrl+Num + / Ctrl+Num - | Vælg alle / vælg ingen |
| Ctrl+A | Vælg alle |
| Alt+Num + | Vælg alle filer med samme filtype |
| Num / | Gendan den forrige markering |

|---|---|
| Ctrl+T | Ny fane |

| Ctrl+Shift+W | Luk alle faner |

## Bemærkninger

- Nogle få TC Classic-taster kolliderer med macOS-systemgenveje. Ctrl+Venstre, Ctrl+Højre, Ctrl+Op og Ctrl+Ned bruges af Mission Control og Spaces; hvis de ikke virker i Peach Commander, justér dem i Systemindstillinger eller ombind dem i Konfiguration-menuen.
- macOS Native-skemaet flytter almindelige handlinger til Command-tasten, mens funktionstasthandlingerne beholdes de samme. Skift skema, eller ændr enhver enkelt tast, fra Konfiguration-menuen.
- Tryk på Esc for at annullere en dialog, rydde kommandolinjen eller lukke Hurtigvisning-panelet.
