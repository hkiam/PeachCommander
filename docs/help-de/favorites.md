Favoriten (die Verzeichnis-Hotlist) sind schnelle Verknüpfungen zu Ordnern, die Sie ständig öffnen. Statt sich immer wieder durch denselben Pfad zu klicken, sichern Sie ihn einmal und springen aus einem kurzen Menü direkt dorthin zurück — von jedem Panel aus, jederzeit. Sie können eine flache Liste führen oder verwandte Ordner in Untermenüs gruppieren (zum Beispiel alle Ihre Projektordner unter einer Überschrift „Projekte").

## Das Favoritenmenü öffnen

1. Machen Sie das Panel, in dem Sie navigieren möchten, zum aktiven (klicken Sie hinein).
2. Drücken Sie Ctrl+D oder wählen Sie **Gehe zu ▸ Verzeichnis-Hotlist…**.
3. Das Favoritenmenü erscheint neben dem Panel. Klicken Sie auf einen Ordner, um ihn dort zu öffnen.

Ihre ersten neun Favoriten sind im Menü nummeriert, sodass Sie sie durch Drücken von 1 bis 9 auswählen können, sobald das Menü geöffnet ist.

## Den aktuellen Ordner hinzufügen

1. Öffnen Sie im aktiven Panel den Ordner, den Sie sich merken möchten.
2. Drücken Sie Ctrl+D, um das Favoritenmenü zu öffnen.
3. Wählen Sie **Aktuelles Verzeichnis hinzufügen**. Der Ordner wird am Ende der Liste hinzugefügt und ist sofort verfügbar.

## Ihre Favoriten organisieren

1. Öffnen Sie das Favoritenmenü und wählen Sie **Hotlist organisieren…**.
2. Bearbeiten Sie im geöffneten Fenster den **Titel** und **Pfad** jedes Favoriten direkt in der Tabelle. Doppelklicken Sie auf eine Zelle, um sie zu ändern.
3. Ziehen Sie Zeilen, um sie neu anzuordnen — die Reihenfolge hier ist die Reihenfolge, in der sie im Menü erscheinen.
4. Verwenden Sie die Schaltflächen, um einen neuen Favoriten oder eine Trennlinie hinzuzufügen.
5. Um Favoriten in einem Untermenü zu gruppieren, setzen Sie einen Backslash in den Titel: Ein Favorit mit dem Titel `Projekte\Website` erscheint unter einem Untermenü **Projekte** als **Website**. Auf diese Weise können Sie mehrere Ebenen verschachteln.
6. Schließen Sie das Fenster, um zu sichern. Ihre Favoriten bleiben zwischen den Starts erhalten.

## Der Stern-Chip

Über der Dateiliste jedes Panels befindet sich ein kleiner **★**-Chip. Klicken Sie darauf, um ein Menü häufiger Orte zu öffnen (Persönlicher Ordner, Schreibtisch, Downloads und so weiter), gefolgt von Ihren Favoriten. Es ist eine schnelle Möglichkeit, einen Favoriten zu erreichen, ohne zuerst das aktive Panel zu wechseln — der Ordner öffnet sich in diesem Panel. Dasselbe Menü hat einen Eintrag **Verzeichnis-Hotlist…**, der die Organisationsfunktion öffnet.

## Kurzbefehle

| Aktion | Kurzbefehl |
| --- | --- |
| Das Favoritenmenü öffnen | Ctrl+D |
| Den aktuellen Ordner hinzufügen | Ctrl+D, dann Aktuelles Verzeichnis hinzufügen |
| Einen der ersten neun Favoriten auswählen | 1–9 (bei geöffnetem Menü) |

## Hinweise

- Ein Titel aus einem einzelnen Bindestrich (`-`) erzeugt eine Trennlinie im Menü, praktisch zum Auftrennen von Gruppen.
- Favoriten werden von beiden Panels gemeinsam genutzt — dieselbe Liste erscheint überall dort, wo Sie das Menü öffnen.
- Das Menü zeigt Nummernkurzbefehle (1–9) nur für die ersten neun Favoriten; die übrigen sind weiterhin vorhanden und anklickbar, nur ohne Nummer.
