Peach Commander está diseñado para el teclado: casi todo lo que hace con el ratón tiene una tecla asociada. Esta página agrupa los atajos predeterminados por tarea para que pueda encontrar el que necesita de un vistazo. Las teclas que se muestran aquí corresponden al esquema **TC Classic** predeterminado (el que esperan los usuarios veteranos de Total Commander). Si prefiere las teclas al estilo de Mac, cambie al esquema **macOS Native** en el menú Configuración, donde las mismas acciones pasan a combinaciones con la tecla Command (por ejemplo, Cmd+C para copiar, Cmd+F para buscar). También puede invalidar cualquier tecla individual.

## Teclas de función

Muchas acciones básicas residen en las teclas de función. Si al pulsar F5 se cambia el volumen en lugar de copiar, active "Usar las teclas F1, F2, etc. como teclas de función estándar" en Ajustes del Sistema, o mantenga pulsada Fn mientras pulsa la tecla.

| Tecla | Acción |
|---|---|
| F1 | Abrir la Ayuda |
| F2 | Actualizar el panel activo |
| F3 | Ver el archivo bajo el cursor |
| F4 | Editar el archivo bajo el cursor |
| F5 | Copiar la selección al otro panel |
| F6 | Mover o renombrar al otro panel |
| F7 | Crear una carpeta nueva |
| F8 o Delete | Eliminar (mover a la Papelera) |
| Shift+F5 | Copiar dentro de la misma carpeta |
| Shift+F6 | Renombrar sobre la marcha |
| Shift+F8 | Eliminar permanentemente (omitir la Papelera) |

## Navegación

| Tecla | Acción |
|---|---|
| Tab | Cambiar el panel activo |
| Enter | Abrir la carpeta, el archivo comprimido o el archivo bajo el cursor |
| Backspace | Ir a la carpeta principal |
| Ctrl+PageUp | Ir a la carpeta principal |
| Ctrl+PageDown | Abrir la carpeta o el archivo comprimido bajo el cursor |
| Alt+Left / Alt+Right | Retroceder / avanzar en el historial |
| Alt+Down | Mostrar la lista del historial |
| Ctrl+\ | Ir a la raíz del volumen |
| Ctrl+D | Abrir los favoritos (lista rápida de directorios) |

## Selección

| Tecla | Acción |
|---|---|
| Insert | Alternar la selección y bajar |
| Space | Alternar la selección (y calcular el tamaño de la carpeta) |
| Num + | Seleccionar por máscara |
| Num - | Deseleccionar por máscara |
| Num * | Invertir la selección |
| Ctrl+Num + / Ctrl+Num - | Seleccionar todo / no seleccionar nada |
| Ctrl+A | Seleccionar todo |
| Alt+Num + | Seleccionar todos los archivos con la misma extensión |
| Num / | Restaurar la selección anterior |

## Operaciones con archivos

| Tecla | Acción |
|---|---|
| F5 | Copiar |
| F6 | Mover o renombrar |
| F7 | Carpeta nueva |
| F8 / Delete | Eliminar a la Papelera |
| Ctrl+M | Herramienta de renombrado múltiple |
| Ctrl+C / Ctrl+X / Ctrl+V | Copiar / cortar / pegar archivos |
| Ctrl+L | Calcular el tamaño de la selección |
| Alt+Enter | Mostrar información y propiedades |

## Vista

| Tecla | Acción |
|---|---|
| Ctrl+F1 | Vista breve |
| Ctrl+F2 | Vista completa (detalles) |
| Ctrl+Shift+F1 | Vista de miniaturas |
| Ctrl+F8 | Vista de árbol en el panel |
| Ctrl+F3 / F4 / F5 / F6 | Ordenar por nombre / extensión / tamaño / fecha |
| Ctrl+H | Mostrar u ocultar los archivos ocultos |
| Ctrl+Q | Alternar el panel de Vista rápida |

## Búsqueda

| Tecla | Acción |
|---|---|
| Alt+F7 | Buscar archivos |
| Ctrl+S | Filtro rápido (restringir los archivos visibles) |
| Ctrl+B | Vista de rama (aplanar todas las subcarpetas) |

## Red

| Tecla | Acción |
|---|---|
| Ctrl+F | Abrir el gestor de conexiones |
| Ctrl+N | Nueva conexión |
| Ctrl+Shift+F | Desconectar |

## Pestañas

| Tecla | Acción |
|---|---|
| Ctrl+T | Pestaña nueva |
| Ctrl+Shift+T | Pestaña nueva en segundo plano |
| Ctrl+W o Ctrl+F4 | Cerrar la pestaña actual |
| Ctrl+Shift+W | Cerrar todas las pestañas |
| Ctrl+Tab / Ctrl+Shift+Tab | Pestaña siguiente / anterior |

## Notas

- Algunas teclas de TC Classic chocan con los atajos del sistema de macOS. Ctrl+Left, Ctrl+Right, Ctrl+Up y Ctrl+Down las usan Mission Control y Spaces; si no funcionan en Peach Commander, ajústelas en Ajustes del Sistema o reasígnelas en el menú Configuración.
- El esquema macOS Native traslada las acciones comunes a la tecla Command mientras mantiene iguales las acciones de las teclas de función. Cambie de esquema, o modifique cualquier tecla individual, desde el menú Configuración.
- Pulse Esc para cancelar un cuadro de diálogo, borrar la línea de comandos o cerrar el panel de Vista rápida.
