Peach Commander è costruito per la tastiera: quasi tutto ciò che fai con il mouse ha un tasto. Questa pagina raggruppa le scorciatoie predefinite per compito, così puoi trovare quella che ti serve con un colpo d'occhio. I tasti mostrati qui sono quelli dello schema predefinito **TC Classic** (quello che si aspettano gli utenti di lunga data di Total Commander). Se preferisci i tasti in stile Mac, passa allo schema **macOS Native** nel menu Configurazione, dove le stesse azioni passano a combinazioni con il tasto Comando (per esempio Cmd+C per copiare, Cmd+F per cercare). Puoi anche sostituire qualsiasi singolo tasto.

## Tasti funzione

Molte azioni fondamentali risiedono sui tasti funzione. Se premere F5 cambia il volume invece di copiare, attiva "Usa i tasti F1, F2, ecc. come tasti funzione standard" in Impostazioni di Sistema, o tieni premuto Fn mentre premi il tasto.

| Tasto | Azione |
|---|---|
| F1 | Apri l'Aiuto |
| F2 | Aggiorna il pannello attivo |
| F3 | Visualizza il file sotto il cursore |
| F4 | Modifica il file sotto il cursore |
| F5 | Copia la selezione nell'altro pannello |
| F6 | Sposta o rinomina nell'altro pannello |
| F7 | Crea una nuova cartella |
| F8 o Canc | Elimina (sposta nel Cestino) |
| Maiusc+F5 | Copia nella stessa cartella |
| Maiusc+F6 | Rinomina sul posto |
| Maiusc+F8 | Elimina definitivamente (salta il Cestino) |

## Navigazione

| Tasto | Azione |
|---|---|
| Tab | Cambia il pannello attivo |
| Invio | Apri la cartella, l'archivio o il file sotto il cursore |
| Backspace | Vai alla cartella superiore |
| Ctrl+PagSu | Vai alla cartella superiore |
| Ctrl+PagGiù | Apri la cartella o l'archivio sotto il cursore |
| Alt+Sinistra / Alt+Destra | Indietro / avanti nella cronologia |
| Alt+Giù | Mostra l'elenco della cronologia |
| Ctrl+\ | Vai alla radice del volume |
| Ctrl+D | Apri i preferiti (elenco rapido delle cartelle) |

## Selezione

| Tasto | Azione |
|---|---|
| Ins | Commuta la selezione e scendi |
| Spazio | Commuta la selezione (e calcola la dimensione della cartella) |
| Num + | Seleziona per maschera |
| Num - | Deseleziona per maschera |
| Num * | Inverti la selezione |
| Ctrl+Num + / Ctrl+Num - | Seleziona tutto / non selezionare nulla |
| Ctrl+A | Seleziona tutto |
| Alt+Num + | Seleziona tutti i file con la stessa estensione |
| Num / | Ripristina la selezione precedente |

## Operazioni sui file

| Tasto | Azione |
|---|---|
| F5 | Copia |
| F6 | Sposta o rinomina |
| F7 | Nuova cartella |
| F8 / Canc | Elimina nel Cestino |
| Ctrl+M | Strumento di rinomina multipla |
| Ctrl+C / Ctrl+X / Ctrl+V | Copia / taglia / incolla file |
| Ctrl+L | Calcola la dimensione della selezione |
| Alt+Invio | Mostra informazioni e proprietà |

## Vista

| Tasto | Azione |
|---|---|
| Ctrl+F1 | Vista breve |
| Ctrl+F2 | Vista completa (dettagli) |
| Ctrl+Maiusc+F1 | Vista miniature |
| Ctrl+F8 | Vista ad albero nel pannello |
| Ctrl+F3 / F4 / F5 / F6 | Ordina per nome / estensione / dimensione / data |
| Ctrl+H | Mostra o nascondi i file nascosti |
| Ctrl+Q | Commuta il pannello di Anteprima rapida |

## Ricerca

| Tasto | Azione |
|---|---|
| Alt+F7 | Trova file |
| Ctrl+S | Filtro rapido (restringe i file visibili) |
| Ctrl+B | Vista a ramo (appiattisce tutte le sottocartelle) |

## Rete

| Tasto | Azione |
|---|---|
| Ctrl+F | Apri il gestore delle connessioni |
| Ctrl+N | Nuova connessione |
| Ctrl+Maiusc+F | Disconnetti |

## Schede

| Tasto | Azione |
|---|---|
| Ctrl+T | Nuova scheda |
| Ctrl+Maiusc+T | Nuova scheda in background |
| Ctrl+W o Ctrl+F4 | Chiudi la scheda corrente |
| Ctrl+Maiusc+W | Chiudi tutte le schede |
| Ctrl+Tab / Ctrl+Maiusc+Tab | Scheda successiva / precedente |

## Note

- Alcuni tasti TC Classic entrano in conflitto con le scorciatoie di sistema macOS. Ctrl+Sinistra, Ctrl+Destra, Ctrl+Su e Ctrl+Giù sono usati da Mission Control e Spaces; se non funzionano in Peach Commander, regolali in Impostazioni di Sistema o riassegnali nel menu Configurazione.
- Lo schema macOS Native sposta le azioni comuni sul tasto Comando mantenendo invariate le azioni dei tasti funzione. Cambia schema, o cambia qualsiasi singolo tasto, dal menu Configurazione.
- Premi Esc per annullare una finestra, cancellare la riga di comando o chiudere il pannello di Anteprima rapida.
