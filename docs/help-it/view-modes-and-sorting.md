Ogni pannello può mostrare la sua cartella nel layout più adatto al compito: un elenco dettagliato con colonne, un elenco compatto a più colonne di nomi, una griglia di icone, una galleria con miniature grandi o un albero delle cartelle. Puoi anche ordinare l'elenco per nome, tipo di file, dimensione o data, scegliere esattamente quali colonne mostrare e attivare l'ordinamento naturale (numerico), così i nomi con numeri si allineano come ti aspetti. La modalità di visualizzazione, l'ordinamento e le colonne si impostano per pannello, così i due lati possono avere un aspetto completamente diverso.

## Cambia modalità di visualizzazione

1. Fai clic sul pannello che vuoi modificare così che diventi attivo.
2. Apri il menu Vista e scegli una modalità: **Completa (Dettagli)** per l'elenco a colonne, **Breve (Colonne)** per un elenco denso a più colonne di nomi, **Icone** per una griglia di icone, **Miniature (Galleria)** per anteprime grandi, o **Albero** per un albero delle cartelle.
3. Per scorrere rapidamente le modalità senza aprire il menu, premi Cmd+Maiusc+M. Ogni pressione passa alla modalità successiva.

## Ordina l'elenco dei file

1. Nella vista Dettagli, fai clic su un'intestazione di colonna (Nome, Tipo, Dimensione o Data) per ordinare in base a essa. Una piccola freccia nell'intestazione mostra la colonna e la direzione di ordinamento correnti.
2. Fai di nuovo clic sulla stessa intestazione per invertire l'ordine.
3. Puoi anche scegliere Vista > Ordina per e scegliere Nome, Tipo di file, Dimensione, Data o Non ordinato.

Le cartelle sono sempre ordinate insieme in cima, prima dei file, e la voce `..` che ti porta su di un livello viene fissata per prima. L'ordinamento per nome o tipo di file è crescente (dalla A alla Z) per impostazione predefinita; l'ordinamento per dimensione o data è dal più recente o più grande per impostazione predefinita.

## Scegli quali colonne mostrare

1. Scegli Configurazione > Colonne….
2. Attiva o disattiva le colonne e imposta il loro ordine. Le colonne disponibili includono Nome, Tipo, Dimensione, Data, Attr (attributi), Etichette e Commento.
3. Applica le modifiche. Le colonne interessano la vista Dettagli del pannello attivo.

## Scorciatoie

| Azione | Scorciatoia |
|---|---|
| Scorri le modalità di visualizzazione | Cmd+Maiusc+M |
| Vista Breve (colonne) | Ctrl+F1 |
| Vista Completa (dettagli) | Ctrl+F2 |
| Vista Miniature (galleria) | Ctrl+Maiusc+F1 |
| Vista Albero | Ctrl+F8 |
| Ordina per nome | Ctrl+F3 |
| Ordina per tipo di file | Ctrl+F4 |
| Ordina per dimensione | Ctrl+F5 |
| Ordina per data | Ctrl+F6 |

## Suggerimenti

- L'ordinamento naturale (numerico) è attivo per impostazione predefinita, così `file2` viene prima di `file10` invece che dopo. Puoi disattivarlo in Configurazione > Opzioni nelle impostazioni di visualizzazione.
- Puoi rendere una colonna più larga o più stretta nella vista Dettagli trascinando la linea di divisione tra le intestazioni delle colonne.
- La modalità di visualizzazione, l'ordinamento e la scelta delle colonne sono ricordati per pannello, così puoi avere un lato come elenco dettagliato e l'altro come galleria fotografica.
