AI 어시스턴트는 자연어로 파일 작업을 돕는 선택적이고 제거 가능한 플러그인입니다. 문서를 요약하거나 설명하고, 더 나은 파일 이름을 제안하고, 텍스트를 번역하거나 교정하고, 데이터를 표로 만들고, 심지어 폴더를 정리할 수도 있습니다. 또한 먼저 계획을 보여준 후 파일 작업을 대신 수행할 수 있습니다. 가능한 경우 Apple Intelligence를 사용하여 기기에서 실행되며, 클라우드 모델을 지정할 수도 있습니다. 플러그인이므로 **설정 ▸ 플러그인…**에서 완전히 비활성화하거나 제거할 수 있습니다.

## 어시스턴트 열기

**명령 ▸ AI Assistant**를 선택하면 창 오른쪽의 고정된 패널에 어시스턴트가 표시됩니다. 요청을 입력하고 Return을 누르십시오. 어시스턴트는 파일을 읽고, 정보를 찾고, 사용자의 확인을 거쳐 변경을 수행할 수 있습니다.

## 마우스 오른쪽 버튼 동작(AI ▸)

어시스턴트를 사용하는 가장 빠른 방법은 마우스 오른쪽 버튼 메뉴의 **AI ▸** 하위 메뉴입니다.

- **파일에서** — 요약, 설명, 이름 제안, 주석 제안, 영어로 번역, 교정, 작업 감지, 표 만들기.
- **패널 배경에서** — 이 폴더 정리 및 중복 가능성 찾기.

각 **AI ▸** 동작은 **고유한 제목의 채팅**(예: *요약 – report.txt*)을 열므로, 서로 다른 작업이 하나의 긴 대화로 쌓이지 않고 분리된 상태를 유지합니다. 입력 필드에 직접 입력하면 그 요청은 현재 채팅을 이어갑니다.

## 채팅 관리

- 패널 상단의 채팅 전환기를 사용하여 대화 사이를 이동합니다.
- **삭제 ▾** 메뉴는 **이 채팅 삭제**와 **모든 채팅 삭제**를 제공하므로, 목록이 길어지면 한 번에 모두 지울 수 있습니다. 빈 채팅은 패널을 닫을 때 자동으로 정리됩니다.

## 변경은 먼저 확인합니다

파일을 수정하는 모든 작업(이동, 이름 바꾸기, 쓰기, 삭제)에 대해 어시스턴트는 실행 전에 **계획을 보여주고 사용자의 확인을 기다립니다**. 설정에서 어시스턴트의 자율성을 높이거나, 아무것도 변경하지 않도록 읽기 전용으로 낮출 수 있습니다.

## 설정

**설정 ▸ Settings ▸ AI**를 열어 한 페이지에서 어시스턴트를 구성할 수 있습니다.

- **선호 모델** — 자동(구성된 경우 클라우드, 그렇지 않으면 기기 내), 기기 내(Apple Intelligence), 또는 클라우드.
- **클라우드 엔드포인트, 모델, API 키** — 기기 내 모델 대신 OpenAI 호환 모델을 사용합니다. 키는 구성 파일이 아니라 macOS 키체인에 저장됩니다.
- **어시스턴트 자율성** — 읽기 전용, 변경 확인(기본값), 또는 자율.
- **사용자 지정 시스템 프롬프트** — 어시스턴트의 응답 방식을 형성하는 선택적 지침.
- **MCP 서버** — 외부 에이전트가 앱을 제어할 수 있게 하는 선택적 로컬 전용 서버. 기본적으로 꺼져 있으며 토큰으로 보호할 수 있습니다.

## 개인정보 보호

- Apple Intelligence를 사용하면 어시스턴트는 **사용자의 Mac에서** 실행되며, 어떤 것도 기기를 떠나지 않습니다.
- 클라우드 모델은 **구성한 경우에만** 사용되며, API 키는 키체인에 보관됩니다.
- 자율성 수준을 의도적으로 높이지 않는 한, 파일을 변경하는 동작은 실행 전에 확인됩니다.
