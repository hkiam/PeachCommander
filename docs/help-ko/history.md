전체 기록은 사용자의 작업 이력을 기억하는 하나의 창입니다. 방문한 폴더, 열어본 파일, 수행한 작업, 실행한 명령이 모두 담깁니다. 어디서든 Ctrl+Cmd+H를 누르고 입력을 시작하면, 마우스 없이 1초 만에 어제의 폴더로 돌아갑니다.

## 기록 열기

1. Ctrl+Cmd+H를 누르거나 **이동 > 기록…**을 선택합니다. 어느 패널이 활성 상태인지는 상관없습니다.
2. 몇 글자만 입력하십시오. 정확하거나 연속된 일치는 필요하지 않습니다. `proj rep`으로 `~/Projects/annual-report.txt`를 찾습니다.
3. 계속 입력하면서 위·아래 화살표 키로 결과를 이동합니다.
4. Return은 강조된 항목을 실행하고, Esc는 창을 닫습니다.

항목은 얼마나 최근에 *그리고* 얼마나 자주 사용했는지에 따라 정렬되므로, 가장 많이 작업하는 위치가 이미 위쪽에 있습니다. 고정된 항목은 항상 맨 앞에 옵니다.

## 종류별 필터

검색 필드 아래의 버튼은 목록을 전체 항목, 폴더, 파일, 작업 또는 즐겨찾기로 제한합니다. Option+1에서 Option+5까지로 키보드에서 전환할 수 있습니다.

## 항목에 대한 동작

| 동작 | 키보드 단축키 |
| --- | --- |
| 강조된 항목 열기 | Return |
| 패널에서 보기(커서를 해당 항목에) | Option+Return |
| 가장 관련 높은 아홉 항목 중 하나 열기 | Cmd+1 … Cmd+9 |
| 열리는 패널 전환 | Tab |
| 항목 고정 또는 해제 | Cmd+P |
| 기록에서 항목 제거 | Cmd+Delete |
| 항목 경로 복사 | Option+Cmd+C |
| Finder에서 항목 보기 | Cmd+Shift+R |
| 기록 닫기 | Esc |

Return은 항목에 맞는 동작을 합니다. 폴더는 대상 패널에서 열리고, 파일은 패널에서와 같은 방식으로 열리며, 명령줄은 확인한 뒤 실행할 수 있도록 명령줄에 놓입니다. 대상 패널은 창 아래쪽에 표시되고 Tab으로 바꿉니다.

## 작업 반복

복사나 이동은 **작업** 아래에 나타나며 Return으로 다시 실행됩니다. 같은 항목을 같은 폴더로, 일반 전송 대기열과 그 덮어쓰기 질문을 그대로 거칩니다. 더 이상 없는 항목은 건너뛰고, 하나도 남지 않으면 그 사실을 알려 줍니다.

삭제와 이름 변경도 목록에 있지만 절대 반복되지 않습니다. Return은 대신 그 일이 있었던 위치를 보여 줍니다. 훑어보는 목록에서 삭제 반복이 키 하나 거리에 있어서는 안 됩니다.

## 적절한 크기로 유지

설정 ▸ 기타에서 기록을 남길지, 항목을 몇 개까지 보관할지, 며칠 후에 잊을지 정합니다. 고정된 항목은 예외이며 0일은 모두 보관한다는 뜻입니다. 목록은 설정 폴더의 `history.ini`에 저장되어 재시작 후에도 남습니다.

## 참고

- 기록에서 무엇을 여는 것도 사용으로 계산됩니다. 그래서 자주 돌아가는 항목이 계속 위로 올라옵니다.
- 서버와 플러그인 드라이브의 폴더도 기억합니다. 더 이상 연결할 수 없는 폴더는 시도할 때 그 사실을 알려 줍니다.
- 이것은 Alt+아래 화살표의 패널별 폴더 기록과 다릅니다. 그것은 해당 패널이 지나온 곳만 순서대로 나열합니다.
