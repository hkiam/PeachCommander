Peach Commander는 두 개의 파일 목록을 나란히 표시하므로, 파일이 어디에서 오고 어디로 가는지 동시에 볼 수 있습니다. 대부분의 작업은 이 두 패널에서 이루어집니다. 그 주위의 막대를 통해 키보드를 떠나지 않고도 드라이브를 전환하고, 폴더로 이동하고, 공통 파일 명령을 실행할 수 있습니다. 이 안내는 창의 각 부분에 이름을 붙여, 나머지 도움말을 이해할 수 있게 합니다.

![두 패널과 주위의 막대가 있는 Peach Commander 주 창](screenshots/main-window.png)
*(그림: 주 창 — 위에 버튼 막대, 드라이브 막대, 경로 막대, 아래에 기능 키 막대가 있는 두 패널.)*

## 두 패널과 활성 패널

창은 왼쪽 패널과 오른쪽 패널로 나뉘며, 각각 한 폴더의 내용을 표시합니다. 한 번에 하나의 패널만 활성입니다. 활성 패널은 커서(강조된 행)를 보여주고 경로 막대가 색이 있는 배경으로 그려집니다. 복사와 이동 같은 명령은 항상 활성 패널에 작용하고 파일을 다른 패널로 보냅니다.

1. 패널 아무 곳이나 클릭하여 활성화하거나, Tab을 눌러 둘 사이를 전환합니다.
2. 화살표 키로 활성 패널의 커서를 위아래로 이동합니다.
3. 폴더에서 Enter를 눌러 열거나, 목록 맨 위의 `..`에서 눌러 한 단계 위로 올라갑니다.

## 패널 주위의 막대

- **버튼 막대**(상단): 자주 쓰는 명령을 위한 평면 버튼의 행. 버튼을 클릭하면 해당 명령이 실행됩니다. 버튼을 마우스 오른쪽 버튼으로 클릭하면 막대를 편집합니다.
- **드라이브 막대**: 사용 가능한 디스크나 볼륨마다 버튼 하나가 있고, 각각에 남은 공간이 표시됩니다. 볼륨을 클릭하면 그 패널이 그곳으로 전환됩니다. 오른쪽 클릭하면 추출합니다 — 이동식 볼륨과 마운트된 디스크 이미지에서는 사용할 수 있고, 시동 디스크와 네트워크 공유에서는 흐리게 표시됩니다. 플러그인은 자체 드라이브를 제공할 수 있으며 — Task Manager가 그중 하나입니다 — 다른 볼륨과 똑같이 동작합니다. 패널이 그곳으로 전환되고, 버튼은 선택된 상태로 남으며, 탭에는 드라이브 이름이 표시됩니다.
- **경로 막대**: 현재 폴더를 클릭 가능한 이동 경로로 보여줍니다. 세그먼트를 클릭하면 그 폴더로 바로 이동하고, 경로를 클릭하면 위치를 입력합니다.
- **상태 막대**(각 목록 아래): 패널의 실시간 요약 — 선택된 파일과 폴더의 수, 그리고 총 크기.
- **명령줄**(하단): 현재 폴더에서 실행되는 셸 스타일 명령을 입력할 수 있는 텍스트 필드.
- **기능 키 막대**(맨 아래): F3 보기, F4 편집, F5 복사, F6 이동, F7 새폴더, F8 삭제라고 표시된 여섯 개의 버튼. 버튼을 클릭하거나 해당 키를 누릅니다.

![볼륨 버튼과 여유 공간을 보여주는 드라이브 막대 근접 화면](screenshots/drive-bar-crop.png)
*(그림: 드라이브 막대 — 볼륨마다 버튼 하나와 남은 공간. 볼륨을 오른쪽 클릭하면 추출합니다.)*

## 단축키

| 작업 | 단축키 |
|---|---|
| 활성 패널 전환 | Tab |
| 커서 아래의 폴더/항목 열기 | Enter |
| 한 폴더 위로 가기 | Backspace |
| 파일 보기 | F3 |
| 파일 편집 | F4 |
| 다른 패널로 복사 | F5 |
| 다른 패널로 이동/이름 바꾸기 | F6 |
| 새 폴더 | F7 |
| 삭제(휴지통으로) | F8 |

## 참고

- 기능 키 막대는 수정 키를 누르고 있으면 실시간으로 레이블을 다시 붙입니다. 예를 들어 Shift를 누르고 있으면 F6이 제자리 이름 바꾸기 동작으로 바뀌므로, 버튼은 항상 지금 키가 무엇을 할지 보여줍니다.
- 거의 모든 막대는 표시하거나 숨길 수 있습니다. 버튼 막대, 드라이브 막대, 명령줄, 기능 키 막대를 켜고 끄거나, 두 패널을 나란히가 아니라 위아래로 쌓으려면 보기 및 설정 메뉴를 살펴보십시오.
- 많은 Mac 키보드에서 F키는 기본적으로 미디어 및 밝기 컨트롤로 작동합니다. F3-F8과 함께 Fn 키를 누르고 있거나, 시스템 설정에서 "F1, F2 등의 키를 표준 기능 키로 사용"을 켜서 직접 사용하십시오.
