Peach Commander는 키보드를 위해 만들어졌습니다. 마우스로 하는 거의 모든 작업에 그에 대한 키가 있습니다. 이 페이지는 기본 단축키를 작업별로 그룹화하여 필요한 것을 한눈에 찾을 수 있게 합니다. 여기에 표시된 키는 기본 **TC Classic** 구성(오랜 Total Commander 사용자가 기대하는 것)입니다. Mac 스타일 키를 선호하면 설정 메뉴에서 **macOS Native** 구성으로 전환하십시오. 그러면 같은 동작이 Command 키 조합으로 옮겨집니다(예: 복사에 Cmd+C, 검색에 Cmd+F). 개별 키를 재정의할 수도 있습니다.

## 기능 키

많은 핵심 동작이 기능 키에 있습니다. F5를 눌렀을 때 복사 대신 볼륨이 바뀌면, 시스템 설정에서 "F1, F2 등의 키를 표준 기능 키로 사용"을 켜거나, 키를 누르는 동안 Fn을 누르고 계십시오.

| 키 | 작업 |
|---|---|
| F1 | 도움말 열기 |
| F2 | 활성 패널 새로 고침 |
| F3 | 커서 아래의 파일 보기 |
| F4 | 커서 아래의 파일 편집 |
| F5 | 선택 항목을 다른 패널로 복사 |
| F6 | 다른 패널로 이동 또는 이름 바꾸기 |
| F7 | 새 폴더 만들기 |
| F8 또는 Delete | 삭제(휴지통으로 이동) |
| Shift+F5 | 같은 폴더 내에서 복사 |
| Shift+F6 | 제자리에서 이름 바꾸기 |
| Shift+F8 | 영구 삭제(휴지통 건너뛰기) |

## 탐색

| 키 | 작업 |
|---|---|
| Tab | 활성 패널 전환 |
| Enter | 커서 아래의 폴더, 압축 파일, 파일 열기 |
| Backspace | 상위 폴더로 이동 |
| Ctrl+PageUp | 상위 폴더로 이동 |
| Ctrl+PageDown | 커서 아래의 폴더 또는 압축 파일 열기 |
| Alt+Left / Alt+Right | 기록에서 뒤로 / 앞으로 이동 |
| Alt+Down | 기록 목록 표시 |
| Ctrl+\ | 볼륨의 루트로 이동 |
| Ctrl+D | 즐겨찾기(디렉토리 핫리스트) 열기 |

## 선택

| 키 | 작업 |
|---|---|
| Insert | 선택 토글 후 아래로 이동 |
| Space | 선택 토글(및 폴더 크기 계산) |
| Num + | 마스크로 선택 |
| Num - | 마스크로 선택 해제 |
| Num * | 선택 반전 |
| Ctrl+Num + / Ctrl+Num - | 모두 선택 / 선택 안 함 |
| Ctrl+A | 모두 선택 |
| Alt+Num + | 같은 확장자를 가진 모든 파일 선택 |
| Num / | 이전 선택 복원 |

## 파일 작업

| 키 | 작업 |
|---|---|
| F5 | 복사 |
| F6 | 이동 또는 이름 바꾸기 |
| F7 | 새 폴더 |
| F8 / Delete | 휴지통으로 삭제 |
| Ctrl+M | 여러 파일 이름 바꾸기 도구 |
| Ctrl+C / Ctrl+X / Ctrl+V | 파일 복사 / 잘라내기 / 붙여넣기 |
| Ctrl+L | 선택 항목 크기 계산 |
| Alt+Enter | 정보 및 속성 표시 |

## 보기

| 키 | 작업 |
|---|---|
| Ctrl+F1 | 간략 보기 |
| Ctrl+F2 | 전체(세부 정보) 보기 |
| Ctrl+Shift+F1 | 썸네일 보기 |
| Ctrl+F8 | 패널의 트리 보기 |
| Ctrl+F3 / F4 / F5 / F6 | 이름 / 확장자 / 크기 / 날짜별 정렬 |
| Ctrl+H | 숨김 파일 표시 또는 숨기기 |
| Ctrl+Q | Quick View 패널 토글 |

## 검색

| 키 | 작업 |
|---|---|
| Alt+F7 | 파일 찾기 |
| Ctrl+S | 빠른 필터(보이는 파일 좁히기) |
| Ctrl+B | 브랜치 보기(모든 하위 폴더 평탄화) |

## 네트워크

| 키 | 작업 |
|---|---|
| Ctrl+F | 연결 관리자 열기 |
| Ctrl+N | 새 연결 |
| Ctrl+Shift+F | 연결 끊기 |

## 탭

| 키 | 작업 |
|---|---|
| Ctrl+T | 새 탭 |
| Ctrl+Shift+T | 백그라운드에서 새 탭 |
| Ctrl+W 또는 Ctrl+F4 | 현재 탭 닫기 |
| Ctrl+Shift+W | 모든 탭 닫기 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |

## 참고

- 몇 가지 TC Classic 키는 macOS 시스템 단축키와 충돌합니다. Ctrl+Left, Ctrl+Right, Ctrl+Up, Ctrl+Down은 미션 컨트롤과 스페이스가 사용합니다. Peach Commander에서 동작하지 않으면 시스템 설정에서 조정하거나 설정 메뉴에서 다시 매핑하십시오.
- macOS Native 구성은 기능 키 동작은 그대로 유지하면서 공통 동작을 Command 키로 옮깁니다. 설정 메뉴에서 구성을 전환하거나 개별 키를 변경하십시오.
- Esc를 누르면 대화상자를 취소하거나, 명령줄을 지우거나, Quick View 패널을 닫습니다.
