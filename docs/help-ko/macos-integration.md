Peach Commander는 나머지 Mac이 동작하는 방식대로 동작합니다. 사용하는 앱, 의존하는 Finder 태그, 공유 시트, Quick Look, 심지어 트랙패드 스와이프까지 모두 Finder에서와 똑같이 여기서 동작하므로, 무언가를 처리하기 위해 앱을 떠날 일이 드뭅니다.

## 아무 앱으로나 파일 열기

파일(또는 선택 항목)을 마우스 오른쪽 버튼으로 클릭하여 그에 대한 시스템 동작에 도달합니다.

1. **열기**를 선택하면 Return이 하는 것과 같은 방식으로 항목을 엽니다.
2. **기본 앱으로 열기**를 선택하면 macOS가 그 유형에 일반적으로 사용하는 앱에 넘깁니다.
3. **다음으로 열기**를 가리키면 파일을 열 수 있는 모든 앱 중에서 선택합니다. 각 앱은 이름과 아이콘과 함께 나열됩니다.
4. **다음으로 열기** 하단에서 **기타…**를 선택하여 직접 임의의 응용 프로그램을 찾아봅니다.

## 표시, 공유, 미리 보기

- **Finder에서 표시**는 항목이 선택된 상태로 Finder 창을 엽니다. Finder 고유의 명령이 필요할 때 편리합니다.
- **공유…**는 선택된 파일에 대해 표준 macOS 공유 시트를 엽니다(메일, 메시지, AirDrop, 그리고 시스템 설정에서 활성화한 그 밖의 모든 것).
- **Quick Look**은 앱을 열지 않고도 전체 크기 미리 보기를 표시합니다. Cmd+Y를 누르거나, 보기 메뉴나 마우스 오른쪽 버튼 메뉴에서 선택하십시오.

## Finder 태그

파일을 마우스 오른쪽 버튼으로 클릭하고 **태그**를 가리켜 일곱 개의 표준 Finder 색상 태그(빨강, 주황, 노랑, 초록, 파랑, 보라, 회색)를 토글합니다. 체크 표시는 어떤 태그가 이미 적용되었는지 보여줍니다. 여기서 설정한 태그는 Mac의 다른 모든 곳에서 보는 것과 같은 Finder 태그입니다.

## 여기서 터미널 열기

**파일 ▸ Open Terminal Here**(또는 **명령 ▸ Open Terminal Here**)를 선택하거나 Cmd+Option+T를 눌러, 활성 패널의 폴더를 이미 가리키는 상태로 터미널을 엽니다.

## 서비스 및 트랙패드

- 표준 macOS **서비스** 메뉴가 현재 선택 항목에 작동하므로, 파일을 받아들이는 모든 서비스를 사용할 수 있습니다.
- 트랙패드에서 두 손가락 가로 스와이프는 웹 브라우저처럼 패널의 기록을 이동합니다. 오른쪽으로 스와이프하면 **뒤로**, 왼쪽으로 스와이프하면 **앞으로**입니다.

## 단축키

| 작업 | 단축키 |
| --- | --- |
| Quick Look | Cmd+Y |
| 여기서 터미널 열기 | Cmd+Option+T |

## 참고

- 트랙패드 스와이프 제스처는 시스템 설정에서 **페이지 간 스와이프** 트랙패드 제스처가 켜져 있을 때만 작동합니다.
- 여기서 터미널 열기는 터미널을 실행합니다. 압축 파일 내부를 탐색하는 동안에는 사용할 수 없습니다.
- 태그, Finder에서 표시, 공유, 다음으로 열기는 디스크의 실제 파일에 적용되므로, 압축 파일 내부의 항목이나 상위 폴더(..) 행에는 제공되지 않습니다.
- 일부 macOS 기능은 Peach Commander가 모든 폴더를 읽을 수 있기 전에 권한이 필요합니다. 파일이 없는 것처럼 보이면 전체 디스크 접근 안내(명령 ▸ Full Disk Access…)에 대해 **개인정보 보호 및 보안**을 참조하십시오.
