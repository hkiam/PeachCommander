Peach Commander는 방해되지 않으면서 데이터를 Mac에 두도록 만들어졌습니다. 비밀번호는 macOS 키체인에 맡겨지고, 충돌 정보는 동의 없이 컴퓨터를 떠나지 않으며, 앱은 사용 분석을 수집하지 않습니다. 이 항목에서는 민감한 정보가 어디에 있는지, 그리고 파일 관리자가 일을 하는 데 필요한 하나의 시스템 권한을 어떻게 부여하는지 설명합니다.

## 비밀번호가 저장되는 곳

저장하는 모든 비밀번호나 키 암호 문구 — FTP나 SFTP 연결용, 또는 비밀번호로 보호된 압축 파일을 여는 데 쓰는 것 — 는 macOS **키체인**에 기록됩니다. 시스템이 Wi‑Fi와 웹사이트 로그인에 쓰는 것과 같은 보안 저장소입니다. 비밀번호는 Peach Commander 자체 설정이나 연결 파일에 평문으로 기록되지 않습니다.

1. 연결이나 압축 파일 비밀번호를 저장할 때 기억하기 옵션을 선택합니다.
2. 비밀번호는 계정으로 보호된 로그인 키체인에 저장됩니다.
3. 나중에 저장된 비밀번호를 검토하거나 제거하려면 **키체인 접근** 앱(응용 프로그램 ▸ 유틸리티)을 열고 연결 이름으로 검색합니다.

## 전체 디스크 접근 권한 부여

macOS는 일부 위치 — 메일, 메시지, 그리고 라이브러리 폴더 안의 다른 앱 데이터 — 를 명시적으로 허용할 때까지 비공개로 유지합니다. 파일 관리자는 모든 파일에 접근해야 하므로 Peach Commander는 **전체 디스크 접근**을 요청합니다. 부여하기 전까지 앱은 제한된 접근으로 계속 작동하며, 다만 그 보호된 폴더가 보이지 않을 뿐입니다.

1. **명령 ▸ 전체 디스크 접근…**을 선택하거나, 시작 시 앱이 안내를 제안할 때 **시스템 설정 열기**를 클릭합니다.
2. **시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 전체 디스크 접근**에서 Peach Commander 옆 스위치를 켭니다.
3. 안내가 나오면 앱을 다시 실행합니다.

## 충돌 보고서는 로컬에 남습니다

앱이 예기치 않게 종료되면 macOS는 사용자 자신의 진단 폴더에 충돌 보고서를 기록합니다. 다음 실행 시 Peach Commander가 이를 알아채고 버그 보고서 제출을 돕겠다고 제안합니다 — 다만 사용자 동의가 있을 때만 그렇습니다.

- **Finder에서 보기**로 보고서를 확인하거나, **보고서를 클립보드로 복사**해 직접 버그 보고서에 붙여 넣을 수 있습니다.
- 무엇도 자동으로 전송되지 않으며, 제3자 충돌 보고 서비스도 관여하지 않습니다.

## 참고

- **텔레메트리 없음.** Peach Commander는 사용자 활동을 추적하거나 사용 분석을 어디로도 보내지 않습니다.
- **제한된 접근도 안전합니다.** 전체 디스크 접근을 건너뛰어도 앱은 평소 볼 수 있는 파일을 계속 탐색하고 관리합니다. 시스템 보호 위치만 숨겨질 뿐입니다.
- **저장된 비밀번호는 사용자가 관리합니다.** 자격 증명이 키체인에 있으므로 앱 안이 아니라 표준 macOS 도구로 관리하고 취소합니다.
