Mac 어디에 있든 파일을 찾아야 할 때 — 이름으로, 내용으로, 또는 크기와 날짜로 — 파일 찾기 창을 사용하세요. 하나 이상의 폴더(그리고 그 하위 폴더)를 검색하고, 텍스트 파일과 압축 파일 내부를 들여다볼 수 있으며, 찾은 모든 것을 패널로 바로 보내 결과를 일반 폴더처럼 다룰 수 있습니다.

## 이름으로 파일 찾기

1. 검색하려는 폴더를 표시하는 패널에서 **명령 > 파일 찾기…**를 선택합니다(또는 Cmd+Shift+F).
2. **일반** 탭의 **검색 대상**에 이름 패턴을 입력합니다. `*.pdf`나 `report_*.docx` 같은 와일드카드를 쓸 수 있습니다. 여러 폴더를 한 번에 검색하려면 시작 폴더 필드에 세미콜론(`;`)으로 구분해 나열합니다.
3. **시작**을 클릭합니다. 찾는 대로 아래 결과 목록에 일치 항목이 나타납니다.
4. 결과를 두 번 클릭하면 활성 패널에서 그 파일로 이동하고, 결과를 선택하고 **보기**(F3)를 클릭하면 기본 제공 뷰어에서 엽니다.

## 내용, 크기, 날짜로 검색

1. 파일 내부를 검색하려면 **일반** 탭의 **텍스트 찾기**에 텍스트를 입력합니다 — 그 필드에 있는 내용을 검색하며, 비어 있으면 이름만 검색합니다. 옵션으로 **대소문자 구분**, **온전한 단어**만 일치, 텍스트를 **정규식**으로 처리, **16진수 내용 검색**, 또는 텍스트를 **포함하지 않는** 파일 찾기를 할 수 있습니다.
2. **고급** 탭으로 전환해 **크기**(예: `10K`~`5M`), **수정 날짜** 범위, 또는 최근 N일 내에 변경된 파일로 결과를 좁힙니다.
3. **아카이브 내부 검색**을 켜면 검색이 찾아낸 아카이브 안까지 살펴봅니다 — Enter로 열 수 있는 것과 같은 형식이며, 압축 플러그인이 추가한 형식도 포함됩니다. 열지 못한 아카이브는 검색이 끝날 때 알려 드립니다.
4. 이미 선택한 것으로 검색을 제한하려면 시작 전에 **선택한 항목만 검색**을 켭니다.
5. **파일 주석도 검색**을 켜면 각 파일의 내용뿐 아니라 주석에서도 텍스트를 찾습니다. 파일 안에는 그런 말이 전혀 없을 때, 그 파일에 *대해* 적어 둔 말로 다시 찾는 방법입니다 — “고객 원본”, “2026년 내보내기로 대체됨”. 이렇게 찾은 결과는 파일의 한 줄 대신 주석을 보여주고 줄 번호는 표시하지 않습니다. 일치한 곳이 파일의 텍스트 안이 아니기 때문입니다. 대소문자, 단어 단위, 정규식은 내용에서와 똑같이 주석에도 적용됩니다. 16진 검색은 적용되지 않습니다. 주석은 사람이 입력한 텍스트이기 때문입니다. **포함하지 않음**도 어긋나지 않습니다. 내용에도 주석에도 그 텍스트가 없을 때 파일이 목록에 오릅니다. 노트 플러그인을 켜 두었다면 그 노트는 콘텐츠 필드로 제공되며, **Plugins** 탭에서 조건을 걸 수 있습니다 — [플러그인 사용](plugins.md)을 보십시오.
6. 어떤 플러그인은 파일 자체에 없는 텍스트를 만들어 줍니다 — 디컴파일러 플러그인은 `.class`를 자바 소스로 바꿉니다. **플러그인이 제공하는 텍스트 검색**을 켜면 그런 파일은 자기 바이트가 아니라 그 텍스트로 검색되므로, 소스에 있던 표현을 컴파일된 클래스에서 찾을 수 있습니다. 이 항목은 그런 플러그인이 설치되어 있을 때만 나타나며, 더 느립니다: 텍스트를 만들려면 파일마다 디컴파일러를 한 번 실행해야 할 수 있습니다.

![크기와 날짜 필터를 보여 주는 파일 찾기 창의 고급 탭](screenshots/find-files-advanced.png)
*(그림: 고급 탭 — 크기, 날짜, 기타 속성으로 필터링.)*

내용 필드를 더하는 플러그인(예: 이미지 크기)이 있으면 **플러그인** 탭에서 필드가 조건과 일치하도록 요구할 수 있습니다 — 예를 들어 폭이 1000픽셀보다 큰 이미지만.

## Spotlight로 빠른 검색

macOS가 이미 색인한 로컬 폴더의 경우, 일반 탭에서 **Spotlight 사용**을 켜면 거의 즉각적인 결과를 얻습니다. Spotlight는 파일을 훑는 대신 색인을 검색하므로 정규식, 하위 폴더 깊이 제한, 선택 항목만 범위는 무시합니다.

## 결과 재사용 및 넘기기

- **목록 상자로 보내기**는 모든 결과를 임시 목록으로 활성 패널에 넣어, 전체 집합을 한 번에 복사·이동·삭제할 수 있게 합니다.
- **불러오기 / 저장** 탭에서 **템플릿으로 저장…**을 선택하면 현재 검색(패턴과 옵션)을 저장하고 나중에 템플릿 목록에서 다시 고를 수 있습니다.
- **검색 대상**과 **텍스트 찾기**는 각각 최근에 사용한 20개 항목을 최신순으로 기억합니다 — 필드 끝의 화살표를 클릭해 다시 고를 수 있습니다. 같은 항목을 두 번 쓰면 두 줄로 남지 않고 맨 위로 올라가며, 목록은 창을 닫거나 앱을 종료해도 남습니다. **불러오기 / 저장** 탭의 **기록 지우기…**는 둘 다 지웁니다. 저장된 템플릿은 영향을 받지 않습니다.

## 단축키

| 동작 | 단축키 |
| --- | --- |
| 파일 찾기 열기 | Cmd+Shift+F 또는 Option+F7 |
| 검색 시작 / 중지 | 창의 시작 버튼 |
| 선택한 결과 보기 | F3 |

## 참고

- 내용 검색은 로컬 폴더와 아카이브의 경우 파일 전체를 읽습니다. 네트워크 위치에서는 매우 큰 파일을 일부만 읽습니다(대략 16MB, 정규식 사용 시 64MB).
- 압축 파일 내부 검색은 중첩된 압축 파일을 최대 4단계까지 내려갑니다.
- **결과에 폴더 포함**은 파일뿐 아니라 이름이 일치하는 폴더도 나열합니다.
- Spotlight는 색인된 로컬 폴더만 다룹니다. 네트워크 위치나 패턴 기반 일치에는 꺼 두고 파일 찾기가 훑도록 하세요.
