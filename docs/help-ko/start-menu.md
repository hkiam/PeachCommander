**시작** 메뉴는 파일, 편집 등과 나란히 메뉴 막대에 자리 잡은, 여러분만의 개인 메뉴입니다. 직접 정의한 명령을 담고 있어 가장 자주 쓰는 동작이 항상 한 번의 클릭 거리에 있습니다. 고전적인 이중 패널 파일 관리자의 전통에 따라 각 항목은 기본 제공 명령을 실행하거나, 외부 프로그램이나 앱을 실행하거나, 폴더로 바로 이동할 수 있습니다. Peach Commander는 시작 메뉴를 비운 채로 제공하며 여러분이 채우기를 기다립니다.

## 직접 명령 추가하기

1. **시작 > 시작 메뉴 변경…**을 선택합니다. Peach Commander가 사용자 명령 파일을 엽니다(처음에는 주석이 달린 예제와 함께 파일을 만듭니다).
2. 명령마다 한 섹션을 추가합니다. 각 섹션은 대괄호 안의 이름으로 시작하고, 이어서 몇 가지 간단한 키가 옵니다:
   - **cmd** — 실행할 것: 프로그램 경로, 앱, 기본 제공 `cm_` 명령, 또는 여러분의 다른 명령.
   - **param** — 프로그램에 전달할 매개변수. 명령이 실행될 때 자리표시자가 채워집니다: `%P`(원본 폴더), `%N`(현재 파일), `%T`(반대 패널의 폴더), `%M`(반대 패널의 파일), `%S`(선택한 파일).
   - **path** — 시작할 폴더(기본값은 현재 폴더).
   - **menu** — 시작 메뉴에 표시되는 제목.
   - **key** — 선택적 단축키, 예: `C+S+B`.
3. 파일을 저장합니다. 시작 메뉴는 다음에 Peach Commander가 활성화될 때 스스로 갱신되므로 새 항목이 바로 나타납니다.

## 팁

- 현재 폴더를 터미널에서 열려면 **cmd**를 `open`, **param**을 `-a Terminal %P`, **menu**를 `여기서 터미널 열기`로 설정합니다.
- **cmd**를 `cm_` 명령으로 지정하면 기본 제공 동작에 자체 시작 메뉴 항목과 단축키를 줄 수 있습니다.
- 파일에서의 순서가 메뉴에서의 순서이므로, 가장 많이 쓰는 명령을 맨 위에 두세요.

## 참고

- 전체 메뉴 막대를 여러분만의 것으로 대체할 수도 있습니다. **설정 > 메뉴 파일 편집…**을 선택하면 현재의 완전히 현지화된 기본 메뉴에서 만들어진 메뉴 파일이 열립니다. 자유롭게 편집하면 앱이 다음에 활성화될 때 변경이 적용됩니다. 파일을 삭제하면 표준 메뉴 막대가 복원됩니다.
