System Monitor 플러그인은 Mac의 활동을 실시간으로 읽어 창 제목 표시줄에 바로 보여줍니다: CPU, 메모리, 디스크, 네트워크, 그리고 — 하드웨어가 노출하는 경우 — GPU, 배터리, 센서를 위한 작은 칩들. 각 칩은 1초에 한 번 갱신되며, 하나를 클릭하면 이력 그래프와 상세 내역이 담긴 팝업이 나타납니다. 플러그인이므로 **설정 ▸ 플러그인…**에서 켜거나, 구성하거나, 제거할 수 있습니다.

## 제목 표시줄 칩

플러그인이 켜져 있으면 제목 표시줄에 한 줄의 작은 칩들이 자리합니다. 각 칩은 색상 점, 짧은 레이블, 실시간 값(일부는 인라인 스파크라인 포함)으로 이루어집니다:

| 칩 | 표시 내용 |
| --- | --- |
| **CPU** | 코어별 상세와 함께 프로세서 부하 |
| **RAM** | 사용 / 전체 메모리(그리고 유선, 압축, 스왑) |
| **HDD** | 부팅 볼륨 공간과 읽기/쓰기 처리량 |
| **Net** | 다운로드 / 업로드 속도와 총량 |
| **GPU** · **Batt** · **Sens** | GPU 사용률 · 배터리 충전량 및 상태 · 팬 속도와 온도 |

칩을 클릭하면 큰 현재 값, **HISTORY** 스파크라인, **DETAILS** 키/값 목록, 그리고 — CPU의 경우 — 코어별 막대의 **CORE LOAD** 목록이 담긴 팝업이 열립니다.

## 구성하기

**명령 ▸ System Monitor…**를 선택하거나(또는 **설정 ▸ Settings ▸ System Monitor**를 열어) 읽기 표시를 구성합니다:

- **제목 표시줄에 시스템 모니터 표시** — 칩의 마스터 켜기/끄기.
- **프로파일** — 적절한 모듈 세트를 고르는 *최소*, *중간*, *최대* 프리셋.
- **모듈 표** — 각 모듈(CPU, GPU, RAM, HDD, Net, Batt, Sens)을 켜거나 끄고, 색상을 선택하고, 행을 끌어 제목 표시줄에 나타나는 순서를 정합니다. 하드웨어가 보고할 수 없는 모듈은 *(n/a)*로 표시됩니다.

## 참고

- 모든 것은 측정되며 결코 꾸며지지 않습니다: 하드웨어가 데이터를 노출하지 않는 모듈(일부 Mac에서 흔히 GPU나 센서)은 지어낸 숫자를 보여주는 대신 사용 불가 상태로 남습니다. 배터리는 데스크탑에서 사용할 수 없습니다.
- 샘플링은 읽기 표시가 보이는 동안에만 백그라운드 타이머로 실행되며, 그래프를 위해 약 30분의 이력을 유지합니다.
- 모듈 선택, 색상, 순서는 앱의 구성과 함께 저장됩니다.
