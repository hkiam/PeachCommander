버튼 막대는 창 상단을 가로지르는 아이콘 버튼 줄입니다. 각 버튼은 여러분이 직접 정의하는 한 번-클릭 단축입니다: 기본 제공 명령 실행, 외부 프로그램이나 앱 실행, 폴더로 이동, 또는 더 많은 버튼이 담긴 하위 막대 열기. 가장 많이 쓰는 동작을 손 닿는 곳에 두는 가장 빠른 방법이며, 정확히 자신의 작업 방식에 맞출 수 있습니다.

## 버튼 막대 사용자 지정

1. **설정 > 도구 막대 사용자화…**를 선택하거나, 막대를 오른쪽 클릭하고 **버튼 막대 편집…**을 선택합니다.
2. 왼쪽 목록은 현재 버튼을 보여 줍니다. **+**로 버튼 추가, **—**로 구분자 추가, **−**로 선택한 버튼 제거, **↑ / ↓**로 순서 변경.
3. 버튼을 선택하고 오른쪽 양식을 채웁니다:
   - **명령** — 기본 제공 명령을 입력하거나 **선택…**을 클릭해 목록에서 고릅니다. 프로그램이나 앱의 경로, 열 폴더, 또는 하위 막대로 쓸 다른 버튼 막대를 입력할 수도 있습니다.
   - **캡션** — 버튼에 표시되는 레이블과 툴팁.
   - **매개변수**와 **시작 경로** — 외부 프로그램에 전달됩니다. `%P`(원본 폴더), `%N`(현재 파일), `%S`(선택한 파일) 같은 자리표시자는 버튼이 실행될 때 채워집니다.
   - **아이콘** — SF Symbol을 고르거나 파일 또는 앱 자체 아이콘을 쓰고, **아이콘만**을 켜서 캡션을 숨깁니다.
4. **저장**을 클릭합니다. 막대가 즉시 다시 로드됩니다.

*(그림: 버튼 막대는 파일 패널 위에 있으며, 각 버튼은 명령·프로그램·폴더·하위 막대를 실행합니다.)*

## 하위 막대와 넘침

버튼은 *하위 막대* — 첫 번째 위에 겹쳐지는 두 번째 버튼 세트 — 를 열 수 있습니다. 클릭하면 내려가고, 왼쪽의 **◀** 버튼으로 이전 막대로 돌아갑니다. 창 너비에 맞지 않을 만큼 버튼이 많으면 남는 것들이 오른쪽 끝의 **»** 갈매기표 뒤로 접힙니다. 클릭하면 접근할 수 있습니다.

## 버튼에 파일 놓기

파일이나 폴더를 버튼 위로 바로 끌어 놓을 수 있습니다:

- **폴더 버튼** — 놓은 항목이 백그라운드에서 그 폴더로 복사됩니다.
- **프로그램 버튼** — 놓은 항목을 선택으로 삼아 프로그램이 실행됩니다.
- **명령 버튼** — 명령이 평소처럼 실행됩니다.

## 세로 버튼 막대

막대를 창 상단에서 왼쪽 세로 열로 옮기려면 **보기 > 세로 버튼 막대**를 선택합니다. 다시 선택하면 가로 막대로 돌아갑니다.

## 참고

- 막대는 Total Commander와 호환되는 표준 버튼-막대 파일에 저장되므로, 이미 가진 막대를 재사용할 수 있습니다.
- 이 동작에는 기본적으로 키보드 단축키가 지정되지 않지만, 직접 추가할 수 있습니다 — [키보드 단축키](keyboard-shortcuts) 참조.
- 아이콘도 명령도 없는 버튼은 단순 구분자로 표시되어, 관련 버튼을 묶는 데 편리합니다.
