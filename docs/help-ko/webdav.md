WebDAV 서버 — Nextcloud, ownCloud, Synology, 대학의 파일 저장소 — 는 여느 폴더와 마찬가지로 패널에서 탐색할 수 있습니다. 네트워크 메뉴에서 **WebDAV 연결…** 을 고르고 URL을 지정하면, 서버가 활성 패널에 나타납니다.

플러그인이므로 **환경설정 ▸ 플러그인…** 에서 끄거나 제거할 수 있습니다.

## 연결하기

URL은 도착하려는 컬렉션이며, 호스트 앞에 사용자 이름을 씁니다:

```
https://anna@files.example.com/remote.php/dav/files/anna/
```

암호는 따로 묻고, 앱을 통해 **키체인** 에 저장됩니다. 설정 파일에는 절대 들어가지 않습니다. 다음에 연결할 때 비워 두면 저장된 암호가 쓰입니다.

연결한 URL은 모두 기억됩니다 — 최근 서른 개, 최신 것이 앞에 — 다음번에 팝업 메뉴에서 제시됩니다. 그 목록은 `~/Library/Application Support/PeachCommander/webdav/sites.json` 에 있으며 **URL만** 담겨 있습니다. 암호는 결코 그곳에 기록되지 않습니다.

## https를 사용하십시오

인증은 HTTP Basic이며, 사용자 이름과 암호가 base64로 인코딩되어 오간다는 뜻입니다. 암호화가 아니라 인코딩입니다. `https://` 에서는 연결이 이를 보호합니다. `http://` 에서는 사실상 평문이며, 여러분과 서버 사이의 모든 것이 이를 읽을 수 있습니다. 순수한 `http://` 도 허용됩니다. 자기 컴퓨터나 폐쇄된 실험실 망의 서버는 정당한 경우이기 때문입니다. 다만 좋은 기본값은 아닙니다.

## 할 수 있는 일

목록 보기, 읽기, 쓰기, 폴더 만들기, 삭제, 이름 변경, 이동이 모두 동작하며, 이는 WebDAV 동사 `PROPFIND`, `GET`, `PUT`, `MKCOL`, `DELETE`, `MOVE` 에 대응합니다. 그래서 WebDAV 서버 위의 패널은 일상적인 작업에서 디스크 위의 패널처럼 동작합니다.

## 무엇을 예상해야 하는가

**전송은 파일 전체 단위입니다.** 파일은 한 덩어리로 받아오거나 보냅니다. 범위 전송이 없으므로, 큰 파일의 전송이 끊기면 이어받는 대신 처음부터 다시 시작합니다.

**서버 안에서의 복사는 여러분의 Mac을 거칩니다.** 이 플러그인은 `COPY` 동사를 쓰지 않으므로, 서버에서 파일을 복제하면 내려받았다가 다시 올립니다. 느린 회선에서는 서버가 스스로 처리하는 이동이 복사보다 훨씬 빠릅니다.

**아무것도 잠기지 않습니다.** WebDAV의 `LOCK` 을 쓰지 않으므로, 두 사람이 같은 파일을 동시에 쓰면 마지막에 저장한 쪽이 남습니다. 잠금이 없는 네트워크 공유와 똑같습니다.

**Basic 인증만 지원합니다.** Digest, 베어러 토큰, 또는 통합 인증 절차를 요구하는 서버는 연결을 거부합니다. 그런 서버 상당수는 대신 앱 전용 암호를 제공하며, 그것은 여기서 동작합니다.
