Peach Commander er bygget for tastaturet: nesten alt du gjør med musen har en tast for det. Denne siden grupperer standardsnarveiene etter oppgave, så du kan finne den du trenger med ett blikk. Tastene som vises her er standardoppsettet **TC Classic** (det som mangeårige Total Commander-brukere forventer). Foretrekker du Mac-stil-taster, bytt til **macOS Native**-oppsettet i Konfigurasjon-menyen, der de samme handlingene flytter til Command-tastkombinasjoner (for eksempel Cmd+C for å kopiere, Cmd+F for å søke). Du kan også overstyre hvilken som helst enkelttast.

## Funksjonstaster

Mange kjernehandlinger bor på funksjonstastene. Hvis det å trykke F5 endrer volumet ditt i stedet for å kopiere, slå på «Bruk F1-, F2- osv.-tastene som standard funksjonstaster» i Systeminnstillinger, eller hold Fn mens du trykker tasten.

| Tast | Handling |
|---|---|
| F1 | Åpne Hjelp |
| F2 | Oppdater det aktive panelet |
| F3 | Vis filen under markøren |
| F4 | Rediger filen under markøren |
| F5 | Kopier utvalget til det andre panelet |
| F6 | Flytt eller gi nytt navn til det andre panelet |
| F7 | Opprett en ny mappe |
| F8 eller Delete | Slett (flytt til papirkurven) |
| Shift+F5 | Kopier i den samme mappen |
| Shift+F6 | Gi nytt navn på stedet |
| Shift+F8 | Slett permanent (hopp over papirkurven) |

## Navigering

| Tast | Handling |
|---|---|
| Tab | Bytt det aktive panelet |
| Enter | Åpne mappen, arkivet eller filen under markøren |
| Backspace | Gå til foreldremappen |
| Ctrl+PageUp | Gå til foreldremappen |
| Ctrl+PageDown | Åpne mappen eller arkivet under markøren |
| Alt+Venstre / Alt+Høyre | Gå bakover / fremover i historikken |
| Alt+Ned | Vis historikklisten |
| Ctrl+\ | Gå til roten av volumet |
| Ctrl+D | Åpne favorittene (mappehurtiglisten) |

## Utvalg

| Tast | Handling |
|---|---|
| Insert | Veksle utvalg og flytt ned |
| Mellomrom | Veksle utvalg (og beregn mappestørrelse) |
| Num + | Velg etter maske |
| Num - | Opphev valg etter maske |
| Num * | Inverter utvalget |
| Ctrl+Num + / Ctrl+Num - | Velg alle / velg ingen |
| Ctrl+A | Velg alle |
| Alt+Num + | Velg alle filer med samme filtype |
| Num / | Gjenopprett forrige utvalg |

|---|---|

|---|---|
| Ctrl+T | Ny fane |

## Merknader

- Noen få TC Classic-taster kolliderer med macOS-systemsnarveier. Ctrl+Venstre, Ctrl+Høyre, Ctrl+Opp og Ctrl+Ned brukes av Mission Control og Spaces; hvis de ikke virker i Peach Commander, juster dem i Systeminnstillinger eller tilordne dem på nytt i Konfigurasjon-menyen.
- macOS Native-oppsettet flytter vanlige handlinger til Command-tasten mens det beholder funksjonstasthandlingene de samme. Bytt oppsett, eller endre hvilken som helst enkelttast, fra Konfigurasjon-menyen.
- Trykk Esc for å avbryte en dialog, tømme kommandolinjen eller lukke hurtigvisningspanelet.
