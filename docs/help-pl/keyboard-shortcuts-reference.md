Peach Commander jest zbudowany dla klawiatury: prawie wszystko, co robisz myszą, ma klawisz. Ta strona grupuje domyślne skróty według zadania, dzięki czemu możesz znaleźć potrzebny na pierwszy rzut oka. Klawisze pokazane tutaj pochodzą z domyślnego schematu **TC Classic** (tego, którego oczekują wieloletni użytkownicy Total Commandera). Jeśli wolisz klawisze w stylu Mac, przełącz się na schemat **macOS Native** w menu Konfiguracja, gdzie te same akcje przechodzą na kombinacje z klawiszem Command (na przykład Cmd+C do kopiowania, Cmd+F do wyszukiwania). Możesz też zastąpić dowolny pojedynczy klawisz.

## Klawisze funkcyjne

Wiele podstawowych akcji znajduje się na klawiszach funkcyjnych. Jeśli naciśnięcie F5 zmienia głośność zamiast kopiować, włącz „Używaj klawiszy F1, F2 itd. jako standardowych klawiszy funkcyjnych” w Ustawieniach systemowych, lub przytrzymaj Fn podczas naciskania klawisza.

| Klawisz | Akcja |
|---|---|
| F1 | Otwórz Pomoc |
| F2 | Odśwież aktywny panel |
| F3 | Wyświetl plik pod kursorem |
| F4 | Edytuj plik pod kursorem |
| F5 | Kopiuj zaznaczenie do drugiego panelu |
| F6 | Przenieś lub zmień nazwę do drugiego panelu |
| F7 | Utwórz nowy folder |
| F8 lub Delete | Usuń (przenieś do Kosza) |
| Shift+F5 | Kopiuj w tym samym folderze |
| Shift+F6 | Zmień nazwę w miejscu |
| Shift+F8 | Usuń trwale (pomiń Kosz) |

## Nawigacja

| Klawisz | Akcja |
|---|---|
| Tab | Przełącz aktywny panel |
| Enter | Otwórz folder, archiwum lub plik pod kursorem |
| Backspace | Przejdź do folderu nadrzędnego |
| Ctrl+PageUp | Przejdź do folderu nadrzędnego |
| Ctrl+PageDown | Otwórz folder lub archiwum pod kursorem |
| Alt+Lewo / Alt+Prawo | Wstecz / naprzód w historii |

| Ctrl+D | Otwórz ulubione (lista podręczna katalogów) |

|---|---|
| Insert | Przełącz zaznaczenie i przejdź w dół |

| Num + | Zaznacz według maski |
| Num - | Odznacz według maski |

| Alt+Num + | Zaznacz wszystkie pliki z tym samym rozszerzeniem |

| Klawisz | Akcja |
|---|---|
| Ctrl+T | Nowa karta |

## Uwagi

- Kilka klawiszy TC Classic koliduje ze skrótami systemowymi macOS. Ctrl+Lewo, Ctrl+Prawo, Ctrl+Góra i Ctrl+Dół są używane przez Mission Control i Spaces; jeśli nie działają w Peach Commanderze, dostosuj je w Ustawieniach systemowych lub przemapuj je w menu Konfiguracja.
- Schemat macOS Native przenosi popularne akcje na klawisz Command, zachowując akcje klawiszy funkcyjnych bez zmian. Przełącz schemat lub zmień dowolny pojedynczy klawisz z menu Konfiguracja.
- Naciśnij Esc, aby anulować okno dialogowe, wyczyścić wiersz poleceń lub zamknąć panel Szybkiego podglądu.
