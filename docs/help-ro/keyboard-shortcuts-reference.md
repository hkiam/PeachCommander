Peach Commander este construit pentru tastatură: aproape tot ce faceți cu mausul are o tastă. Această pagină grupează comenzile rapide implicite după sarcină, astfel încât să găsiți cea de care aveți nevoie dintr-o privire. Tastele afișate aici sunt din schema implicită **TC Classic** (cea pe care o așteaptă utilizatorii de lungă durată ai Total Commander). Dacă preferați taste în stil Mac, comutați la schema **macOS Native** din meniul Configurare, unde aceleași acțiuni trec la combinații cu tasta Command (de exemplu Cmd+C pentru copiere, Cmd+F pentru căutare). Puteți de asemenea suprascrie orice tastă individuală.

## Taste funcționale

Multe acțiuni de bază se află pe tastele funcționale. Dacă apăsarea F5 vă schimbă volumul în loc să copieze, activați „Folosește tastele F1, F2 etc. ca taste funcționale standard" în Setări de sistem, sau țineți apăsat Fn în timp ce apăsați tasta.

| Tastă | Acțiune |
|---|---|
| F1 | Deschide Ajutorul |
| F2 | Reîmprospătează panoul activ |
| F3 | Vizualizează fișierul de sub cursor |
| F4 | Editează fișierul de sub cursor |
| F5 | Copiază selecția în celălalt panou |
| F6 | Mută sau redenumește în celălalt panou |
| F7 | Creează un folder nou |
| F8 sau Delete | Șterge (mută în Coș) |
| Shift+F5 | Copiază în același folder |
| Shift+F6 | Redenumește pe loc |
| Shift+F8 | Șterge permanent (ocolește Coșul) |

## Navigare

| Tastă | Acțiune |
|---|---|
| Tab | Comută panoul activ |
| Enter | Deschide folderul, arhiva sau fișierul de sub cursor |
| Backspace | Salt la folderul părinte |
| Ctrl+PageUp | Salt la folderul părinte |
| Ctrl+PageDown | Deschide folderul sau arhiva de sub cursor |
| Alt+Stânga / Alt+Dreapta | Înapoi / înainte în istoric |
| Alt+Jos | Arată lista de istoric |
| Ctrl+\ | Salt la rădăcina volumului |
| Ctrl+D | Deschide favoritele (lista rapidă de directoare) |

## Selectare

| Tastă | Acțiune |
|---|---|
| Insert | Comută selecția și coboară |
| Spațiu | Comută selecția (și calculează dimensiunea folderului) |
| Num + | Selectează după mască |
| Num - | Deselectează după mască |
| Num * | Inversează selecția |
| Ctrl+Num + / Ctrl+Num - | Selectează tot / nu selecta nimic |
| Ctrl+A | Selectează tot |
| Alt+Num + | Selectează toate fișierele cu aceeași extensie |
| Num / | Restaurează selecția anterioară |

## Operațiuni cu fișiere

| Tastă | Acțiune |
|---|---|
| F5 | Copiază |
| F6 | Mută sau redenumește |
| F7 | Folder nou |
| F8 / Delete | Șterge în Coș |
| Ctrl+M | Instrument de redenumire multiplă |
| Ctrl+C / Ctrl+X / Ctrl+V | Copiază / taie / lipește fișiere |
| Ctrl+L | Calculează dimensiunea selecției |
| Alt+Enter | Arată informații și proprietăți |

## Vizualizare

| Tastă | Acțiune |
|---|---|
| Ctrl+F1 | Vizualizare scurtă |
| Ctrl+F2 | Vizualizare completă (detalii) |
| Ctrl+Shift+F1 | Vizualizare miniaturi |
| Ctrl+F8 | Vizualizare arbore în panou |
| Ctrl+F3 / F4 / F5 / F6 | Sortează după nume / extensie / dimensiune / dată |
| Ctrl+H | Arată sau ascunde fișierele ascunse |
| Ctrl+Q | Comută panoul de Vizualizare rapidă |

## Căutare

| Tastă | Acțiune |
|---|---|
| Alt+F7 | Găsește fișiere |
| Ctrl+S | Filtru rapid (îngustează fișierele vizibile) |
| Ctrl+B | Vizualizare ramură (aplatizează toate subfolderele) |

## Rețea

| Tastă | Acțiune |
|---|---|
| Ctrl+F | Deschide managerul de conexiuni |

## File

| Tastă | Acțiune |
|---|---|
| Ctrl+T | Filă nouă |
| Ctrl+Shift+T | Filă nouă în fundal |
| Ctrl+W sau Ctrl+F4 | Închide fila curentă |
| Ctrl+Shift+W | Închide toate filele |
| Ctrl+Tab / Ctrl+Shift+Tab | Fila următoare / anterioară |

## Note

- Câteva taste TC Classic intră în conflict cu comenzile rapide de sistem macOS. Ctrl+Stânga, Ctrl+Dreapta, Ctrl+Sus și Ctrl+Jos sunt folosite de Mission Control și Spaces; dacă nu funcționează în Peach Commander, ajustați-le în Setări de sistem sau remapați-le în meniul Configurare.
- Schema macOS Native mută acțiunile comune pe tasta Command păstrând acțiunile tastelor funcționale la fel. Comutați schema, sau schimbați orice tastă individuală, din meniul Configurare.
- Apăsați Esc pentru a anula un dialog, a șterge linia de comandă sau a închide panoul de Vizualizare rapidă.
