Плагин Git показывает состояние репозитория Git прямо в файловой панели — без отдельного приложения, без терминала. Он добавляет две колонки, отображающие статус рабочего дерева каждого файла и текущую ветку, подменю **Git** для повседневных команд (статус, индексирование, коммит, pull, push) и использует `git`, уже установленный на вашем Mac. Поскольку это плагин, вы можете отключить или удалить его в разделе **Конфигурация ▸ Плагины…**.

## Что он добавляет

- **Две колонки в списке файлов** — *Git Status* и *Branch*. В репозитории каждый файл показывает короткое слово состояния (Изменён, Добавлен, Удалён, Не отслеживается, Переименован, Скопирован, Конфликт, Игнорируется или Изменённый), а панель показывает текущую ветку. Включите колонки в **Конфигурация ▸ Колонки…** (см. [Режимы представления и сортировка](view-modes-and-sorting.md)).
- **Меню Git** — в **Команды ▸ Git**, а также в контекстном меню файла, с командами: **Git Status…**, **Git Add (индексировать)**, **Git Commit…**, **Git Pull** и **Git Push**.

## Проверка статуса

1. Поставьте курсор на файл или папку внутри репозитория Git.
2. Выберите **Команды ▸ Git ▸ Git Status…** (или правый щелчок ▸ **Git ▸ Git Status…**).
3. Появляется сводка: текущая ветка (или *(отсоединён)*), затем либо *Рабочее дерево чисто.*, либо список изменений, где каждая строка показывает состояние и путь к файлу.

Если курсор не находится внутри репозитория, плагин просто сообщает *Не является репозиторием Git.*

## Индексирование, коммит, pull, push

- **Git Add (индексировать)** индексирует файл под курсором (`git add`).
- **Git Commit…** запрашивает сообщение коммита, затем фиксирует все изменения (`git commit -a`). Показывается совокупный вывод, чтобы вы могли увидеть, что именно произошло.
- **Git Pull** выполняет pull только с перемоткой вперёд (`git pull --ff-only`).
- **Git Push** отправляет текущую ветку (`git push`).

После команды, изменяющей репозиторий, активная панель обновляется, чтобы колонки статуса оставались актуальными.

## Примечания

- Плагин использует системный Git по адресу `/usr/bin/git`. Если Git не установлен, команды сообщают, что Git недоступен. (Установка Xcode Command Line Tools предоставляет его.)
- Статус репозитория читается один раз для каждой папки и кэшируется, поэтому прокрутка большого репозитория остаётся быстрой; кэш обновляется после любой команды, изменяющей дерево.
- Коммит использует `git commit -a`, который фиксирует отслеживаемые изменения; совершенно новые файлы всё равно требуют сначала **Git Add (индексировать)**.
- Заголовки колонок *Git Status* и *Branch* в настоящее время отображаются на английском даже в других языках интерфейса; значения и диалоги локализованы.
