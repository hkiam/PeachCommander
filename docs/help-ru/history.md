Глобальная история — это одно окно, которое помнит вашу собственную работу: посещённые папки, открытые файлы, выполненные операции и запущенные команды. Нажмите Ctrl+Cmd+H откуда угодно, начните печатать — и через секунду вы снова во вчерашней папке, без мыши.

## Открыть историю

1. Нажмите Ctrl+Cmd+H или выберите **Переход > История…**. Неважно, какая панель активна.
2. Введите несколько букв. Совпадение не обязано быть точным или непрерывным: `proj rep` находит `~/Projects/annual-report.txt`.
3. Перемещайтесь по результатам клавишами вверх и вниз, продолжая печатать.
4. Return выполняет выделенную запись, Esc закрывает окно.

Записи упорядочены по тому, насколько недавно *и* насколько часто вы ими пользовались, поэтому места, где вы работаете больше всего, уже наверху. Закреплённые записи всегда идут первыми.

## Фильтр по виду

Кнопки под полем поиска ограничивают список всеми записями, папками, файлами, операциями или избранным. Option+1 — Option+5 переключают их с клавиатуры.

## Действия с записью

| Действие | Сочетание |
| --- | --- |
| Открыть выделенную запись | Return |
| Показать в панели, с курсором на ней | Option+Return |
| Открыть одну из девяти самых значимых записей | Cmd+1 … Cmd+9 |
| Сменить панель, в которой открывается | Tab |
| Закрепить или снять закрепление | Cmd+P |
| Удалить запись из истории | Cmd+Delete |
| Копировать путь записи | Option+Cmd+C |
| Показать запись в Finder | Cmd+Shift+R |
| Закрыть историю | Esc |

Return делает то, что записи и подобает: папка открывается в целевой панели, файл открывается так же, как из панели, а командная строка попадает в строку команд, чтобы вы её проверили и запустили. Целевая панель названа внизу окна, а Tab её меняет.

## Повторить операцию

Копирование или перемещение появляется в разделе **Операции**, и Return запускает его снова — те же объекты в ту же папку, через обычную очередь передачи и её вопросы о перезаписи. Объекты, которых больше нет, пропускаются, а если не осталось ни одного, вам об этом сообщат.

Удаления и переименования перечислены, но никогда не повторяются: Return вместо этого показывает, где они произошли. Повторение удаления не должно быть в одном нажатии от списка, который вы просто просматриваете.

## Держать её в рамках

Настройки ▸ Прочее решают, ведётся ли история, сколько записей она хранит и через сколько дней их забывает. Закреплённые записи исключены, а 0 дней хранит всё; список лежит в `history.ini` в вашей папке настроек и переживает перезапуски.

## Примечания

- Открыть что-то из истории считается использованием — поэтому то, к чему вы возвращаетесь, продолжает подниматься.
- Папки внутри архива, на сервере или в диске плагина не запоминаются: такой путь ничего не значит без подключения, которое его создало, а собственная история панели хранит их, пока оно открыто.
- Это не собственная история папок панели на Alt+вниз, которая перечисляет лишь то, где была именно эта панель, по порядку.
