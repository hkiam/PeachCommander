Peach Commander создан для клавиатуры: почти для всего, что вы делаете мышью, есть клавиша. Эта страница группирует сочетания по умолчанию по задачам, чтобы вы могли с первого взгляда найти нужное. Показанные здесь клавиши — это схема **TC Classic** по умолчанию (та, которую ожидают давние пользователи Total Commander). Если вы предпочитаете клавиши в стиле Mac, переключитесь на схему **macOS Native** в меню «Конфигурация», где те же действия переходят на комбинации с клавишей Command (например, Cmd+C для копирования, Cmd+F для поиска). Вы также можете переопределить любую отдельную клавишу.

## Функциональные клавиши

Многие основные действия находятся на функциональных клавишах. Если нажатие F5 меняет громкость вместо копирования, включите «Использовать клавиши F1, F2 и т. д. как стандартные функциональные клавиши» в Системных настройках или удерживайте Fn при нажатии клавиши.

| Клавиша | Действие |
|---|---|
| F1 | Открыть справку |
| F2 | Обновить активную панель |
| F3 | Просмотреть файл под курсором |
| F4 | Редактировать файл под курсором |
| F5 | Копировать выборку в другую панель |
| F6 | Переместить или переименовать в другую панель |
| F7 | Создать новую папку |
| F8 или Delete | Удалить (переместить в Корзину) |
| Shift+F5 | Копировать в той же папке |
| Shift+F6 | Переименовать на месте |
| Shift+F8 | Удалить безвозвратно (минуя Корзину) |

## Навигация

| Клавиша | Действие |
|---|---|
| Tab | Переключить активную панель |
| Enter | Открыть папку, архив или файл под курсором |
| Backspace | Перейти в родительскую папку |
| Ctrl+PageUp | Перейти в родительскую папку |
| Ctrl+PageDown | Открыть папку или архив под курсором |
| Alt+Left / Alt+Right | Назад / вперёд по истории |
| Alt+Down | Показать список истории |
| Ctrl+\ | Перейти к корню тома |
| Ctrl+D | Открыть избранное (список закладок каталогов) |

## Выделение

| Клавиша | Действие |
|---|---|
| Insert | Переключить выделение и переместиться вниз |
| Space | Переключить выделение (и вычислить размер папки) |
| Num + | Выделить по маске |
| Num - | Снять выделение по маске |
| Num * | Инвертировать выделение |
| Ctrl+Num + / Ctrl+Num - | Выделить всё / снять всё выделение |
| Ctrl+A | Выделить всё |
| Alt+Num + | Выделить все файлы с тем же расширением |
| Num / | Восстановить предыдущее выделение |

## Файловые операции

| Клавиша | Действие |
|---|---|
| F5 | Копировать |
| F6 | Переместить или переименовать |
| F7 | Новая папка |
| F8 / Delete | Удалить в Корзину |
| Ctrl+M | Инструмент группового переименования |
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать / вырезать / вставить файлы |
| Ctrl+L | Вычислить размер выборки |
| Alt+Enter | Показать сведения и свойства |

## Вид

| Клавиша | Действие |
|---|---|
| Ctrl+F1 | Краткое представление |
| Ctrl+F2 | Полное (подробное) представление |
| Ctrl+Shift+F1 | Представление миниатюр |
| Ctrl+F8 | Представление дерева в панели |
| Ctrl+F3 / F4 / F5 / F6 | Сортировать по имени / расширению / размеру / дате |
| Ctrl+H | Показать или скрыть скрытые файлы |
| Ctrl+Q | Переключить панель быстрого просмотра |

## Поиск

| Клавиша | Действие |
|---|---|
| Alt+F7 | Найти файлы |
| Ctrl+S | Быстрый фильтр (сузить видимые файлы) |
| Ctrl+B | Представление ветви (свести все вложенные папки) |

## Сеть

| Клавиша | Действие |
|---|---|
| Ctrl+F | Открыть диспетчер подключений |
| Ctrl+N | Новое подключение |
| Ctrl+Shift+F | Отключиться |

## Вкладки

| Клавиша | Действие |
|---|---|
| Ctrl+T | Новая вкладка |
| Ctrl+Shift+T | Новая вкладка в фоне |
| Ctrl+W или Ctrl+F4 | Закрыть текущую вкладку |
| Ctrl+Shift+W | Закрыть все вкладки |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая вкладка |

## Примечания

- Несколько клавиш TC Classic конфликтуют с системными сочетаниями macOS. Ctrl+Left, Ctrl+Right, Ctrl+Up и Ctrl+Down используются Mission Control и Spaces; если они не работают в Peach Commander, настройте их в Системных настройках или переназначьте в меню «Конфигурация».
- Схема macOS Native переносит распространённые действия на клавишу Command, сохраняя действия функциональных клавиш неизменными. Переключайте схемы или меняйте любую отдельную клавишу из меню «Конфигурация».
- Нажмите Esc, чтобы отменить диалог, очистить командную строку или закрыть панель быстрого просмотра.
