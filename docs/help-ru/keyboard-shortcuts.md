Peach Commander создан для управления с клавиатуры. Он поставляется с двумя готовыми схемами сочетаний и позволяет переназначить любую команду на предпочитаемые вами клавиши. Если вы пришли из классического двухпанельного файлового менеджера, вы можете сохранить уже знакомые клавиши; если вы предпочитаете привычные комбинации Mac, переключитесь на схему macOS одним щелчком. Обозреватель команд с поиском позволяет открыть для себя всё, что умеет приложение, и выполнить любую команду по имени.

## Переключение схем клавиатуры

1. Откройте меню **Конфигурация**.
2. Выберите **Схема клавиатуры**, затем выберите одну:
   - **TC Classic** (по умолчанию) сохраняет традиционные клавиши с комбинациями на основе Ctrl, такими как Ctrl+R для обновления панели.
   - **macOS Native** сопоставляет те же действия с привычными клавишами Mac, где это имеет смысл, например Cmd+C для копирования файлов и Cmd+F для поиска.
3. Галочка показывает активную схему. Изменение вступает в силу немедленно во всех меню и на полосе сочетаний.

## Настройка сочетаний клавиш

1. Выберите **Конфигурация > Сочетания клавиш…**.
2. Найдите команду с помощью поля поиска, затем выберите её строку.
3. Щёлкните **Записать…** и нажмите нужную комбинацию клавиш. Она назначается сразу.
4. Если эта комбинация уже использовалась другой командой, уведомление сообщит, у какой команды она была отобрана.
5. Используйте **Очистить**, чтобы удалить сочетание команды, или **Восстановить по умолчанию**, чтобы отменить все ваши изменения и вернуться к исходным клавишам схемы.

## Обзор всех команд

1. Выберите **Конфигурация > Обозреватель команд…**.
2. Вводите текст в поле поиска для фильтрации по имени, категории или описанию.
3. Дважды щёлкните команду или выберите её и щёлкните **Выполнить**, чтобы выполнить её на активной панели.

![Обозреватель команд со списком команд с возможностью поиска](screenshots/command-browser.png)
*(Рис.: Все команды в одном списке с поиском, с кратким описанием каждой.)*

## Сочетания клавиш

| Действие | Путь меню |
|---|---|
| Выбрать классическую схему | Конфигурация > Схема клавиатуры > TC Classic |
| Выбрать схему Mac | Конфигурация > Схема клавиатуры > macOS Native |
| Редактировать сочетания | Конфигурация > Сочетания клавиш… |
| Обзор всех команд | Конфигурация > Обозреватель команд… |
| Обновить активную панель | F2 (также Ctrl+R) |

## Примечания

- Ваши пользовательские сочетания сохраняются автоматически и накладываются поверх активной схемы. Переключение схем сохраняет ваши личные переопределения.
- Команды, недоступные в текущем контексте, отображаются приглушёнными как в редакторе сочетаний, так и в обозревателе команд.
- Чтобы использовать функциональные клавиши (F1–F12) напрямую, включите **Использовать клавиши F1, F2 и т. д. как стандартные функциональные клавиши** в Системных настройках > Клавиатура. Иначе удерживайте клавишу **Fn** вместе с функциональной клавишей.
