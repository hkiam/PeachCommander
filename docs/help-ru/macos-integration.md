Peach Commander работает так же, как остальная часть вашего Mac. Приложения, которыми вы пользуетесь, теги Finder, на которые вы полагаетесь, меню «Поделиться», Quick Look и даже жесты трекпада ведут себя здесь точно так же, как в Finder — поэтому вам редко нужно покидать приложение, чтобы что-то сделать.

## Открывайте файлы любым приложением

Щёлкните правой кнопкой по файлу (или выделению), чтобы получить системные действия для него:

1. Выберите **Открыть**, чтобы открыть элемент так же, как по клавише Ввод.
2. Выберите **Открыть в приложении по умолчанию**, чтобы передать его приложению, которое macOS обычно использует для этого типа.
3. Наведите на **Открыть с помощью**, чтобы выбрать из всех приложений, способных открыть файл. Каждое приложение перечислено с именем и значком.
4. Внизу **Открыть с помощью** выберите **Другое…**, чтобы найти любое приложение самостоятельно.

## Показать, поделиться и предпросмотреть

- **Показать в Finder** открывает окно Finder с выделенным элементом — удобно, когда вам нужны собственные команды Finder.
- **Поделиться…** открывает стандартное меню «Поделиться» macOS для выбранных файлов (Почта, Сообщения, AirDrop и всё остальное, что вы включили в Системных настройках).
- **Quick Look** показывает предпросмотр в полный размер без открытия приложения. Нажмите Cmd+Y или выберите его из меню Вид или меню правой кнопки.

## Теги Finder

Щёлкните правой кнопкой по файлу и наведите на **Теги**, чтобы переключить семь стандартных цветных тегов Finder (Красный, Оранжевый, Жёлтый, Зелёный, Синий, Фиолетовый, Серый). Галочка показывает, какие теги уже применены. Теги, заданные здесь, — это те же теги Finder, которые вы видите везде на вашем Mac.

## Открыть терминал здесь

Выберите **Файл ▸ Открыть Терминал здесь** (или **Команды ▸ Открыть Терминал здесь**) или нажмите Cmd+Option+T, чтобы открыть Терминал, уже направленный на папку активной панели.

## Службы и трекпад

- Стандартное меню **Службы** macOS работает с текущим выделением, поэтому доступна любая Служба, принимающая файлы.
- На трекпаде горизонтальный смахивающий жест двумя пальцами перемещает по истории панели как в веб-браузере: смахните вправо, чтобы перейти **Назад**, смахните влево, чтобы перейти **Вперёд**.

## Сочетания клавиш

| Действие | Сочетание |
| --- | --- |
| Quick Look | Cmd+Y |
| Открыть Терминал здесь | Cmd+Option+T |

## Примечания

- Смахивающий жест трекпада срабатывает только когда системный жест трекпада **Смахивание между страницами** включён в Системных настройках.
- «Открыть Терминал здесь» запускает Терминал; он недоступен, пока вы просматриваете содержимое архива.
- Теги, «Показать в Finder», «Поделиться» и «Открыть с помощью» применимы к реальным файлам на диске, поэтому они не предлагаются для элементов внутри архивов или на строке родительской папки (..).
- Некоторым функциям macOS нужно разрешение, прежде чем Peach Commander сможет прочитать каждую папку. Если файлы кажутся отсутствующими, см. **Конфиденциальность и безопасность** для руководства по полному доступу к диску (Команды ▸ Полный доступ к диску…).
