Инструмент группового переименования переименовывает целую партию файлов за один проход. Вместо того чтобы редактировать имена по одному, вы описываете изменение один раз — шаблон именования, поиск и замену, схему нумерации или смену регистра — и Peach Commander применяет его к каждому выбранному файлу. Живой предпросмотр показывает, как именно будет называться каждый файл, до того как что-либо произойдёт, а одно нажатие «Отменить» возвращает исходные имена, если результат оказался не таким, как вы хотели.

## Переименовать партию файлов

1. Выделите файлы, которые хотите переименовать (см. *Выделение файлов*). Затрагиваются только выделенные элементы.
2. Выберите **Команды > Инструмент группового переименования…** или нажмите Ctrl+M.
3. Постройте правило переименования, используя описанные ниже поля. Сетка предпросмотра обновляется по мере ввода, показывая каждое **Старое имя** рядом с его **Новым именем**.
4. Проверьте предпросмотр. Строка, показанная цветом подсветки, отмечает имя, которое нельзя использовать (например, дубликат или недопустимое имя), чтобы вы могли скорректировать правило.
5. Когда предпросмотр выглядит правильно, нажмите **Старт**. Если передумаете, нажмите **Отменить**, чтобы восстановить исходные имена.

## Построение правила переименования

- **Маска имени** и **Расширение** — шаблоны, которые строят новое имя и расширение. Используйте кнопки быстрой вставки или вводите заполнители напрямую: `[N]` для исходного имени, `[N1-9]` для диапазона символов из него, `[C]` для счётчика, `[d]` для частей даты и времени, `[P]` для имени родительской папки.
- **Найти / Заменить на** — замена текста внутри имён. Включите **Регулярное выражение** для сопоставления по шаблону, **С учётом регистра** для точного совпадения регистра и **Повторять** для замены каждого вхождения.
- **Регистр** — преобразовать имена в нижний регистр, ВЕРХНИЙ РЕГИСТР, С заглавной буквы или Каждое Слово С Заглавной.
- **Счётчик** — задайте **начальное** число, **шаг** между файлами и сколько **цифр** дополнять (например, 001, 002, 003) везде, где встречается `[C]`.

## Сочетания клавиш

| Действие | Сочетание |
| --- | --- |
| Открыть инструмент группового переименования | Ctrl+M |
| Применить переименование | Ввод |
| Закрыть окно | Esc |

## Советы

- Ничего не записывается на диск, пока вы не нажмёте **Старт**, поэтому вы можете свободно экспериментировать с правилом и наблюдать за предпросмотром.
- После выполнения **Отменить** обращает переименование за один шаг.
- Сохраните правило, которым часто пользуетесь, как **Пресет**, затем выберите его из меню пресетов в следующий раз, чтобы сразу заполнить все поля.
- Чтобы переименовать один файл или переименовать файлы при перемещении, используйте переименование на месте или диалог перемещения (см. *Перемещение и переименование*).
