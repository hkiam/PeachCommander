Когда нужно отыскать файлы где угодно на вашем Mac — по имени, по содержимому или по размеру и дате — используйте окно «Найти файлы». Оно ищет в одной или нескольких папках (и их подпапках), может заглядывать внутрь текстовых файлов и архивов и позволяет отправить всё найденное прямо в панель, чтобы вы могли работать с результатами как с обычной папкой.

## Найти файлы по имени

1. В панели, показывающей папку для поиска, выберите **Команды > Найти файлы…** (или нажмите Cmd+Shift+F).
2. На вкладке **Общие** введите шаблон имени в поле **Искать**. Можно использовать подстановочные знаки, например `*.pdf` или `report_*.docx`. Чтобы искать в нескольких папках сразу, перечислите их в поле начальной папки через точку с запятой (`;`).
3. Нажмите **Старт**. Совпадения появляются в списке результатов ниже по мере нахождения.
4. Дважды щёлкните по любому результату, чтобы перейти к этому файлу в активной панели, или выделите результат и нажмите **Просмотр** (F3), чтобы открыть его во встроенном просмотрщике.

## Поиск по содержимому, размеру и дате

1. Чтобы искать внутри файлов, выберите **Найти текст** на вкладке «Общие» и введите искомый текст. Параметры позволяют сделать его **с учётом регистра**, совпадать только по **слову целиком**, трактовать текст как **регулярное выражение**, выполнить **шестнадцатеричный поиск содержимого** или найти файлы, **не содержащие** текст.
2. Перейдите на вкладку **Дополнительно**, чтобы сузить результаты по **размеру** (например, от `10K` до `5M`), по диапазону **даты изменения** или по файлам, изменённым за последние N дней.
3. Включите **Искать внутри архивов**, чтобы просматривать архивы семейства zip (zip, jar, war и подобные).
4. Чтобы ограничить поиск уже выбранным, включите **Искать только в выделенных элементах** перед началом.

![Окно «Найти файлы» на вкладке «Дополнительно» с фильтрами размера и даты](screenshots/find-files-advanced.png)
*(Рисунок: вкладка «Дополнительно» — фильтр по размеру, дате и другим атрибутам.)*

Если у вас есть плагины, добавляющие поля содержимого (например, размеры изображения), вкладка **Плагины** позволяет требовать соответствия поля условию — например, только изображения шире 1000 пикселей.

![Окно «Найти файлы» на вкладке «Плагины» с условием по полю содержимого](screenshots/find-files-plugins.png)

## Быстрый поиск через Spotlight

Для локальных папок, которые macOS уже проиндексировало, включите **Использовать Spotlight** на вкладке «Общие» для почти мгновенных результатов. Spotlight ищет по индексу, а не сканирует файлы, поэтому он игнорирует регулярные выражения, ограничения глубины подпапок и область «только выделенное».

## Повторное использование и передача результатов

- **Передать в список** помещает каждый результат в активную панель как временный список, чтобы вы могли скопировать, переместить или удалить весь набор сразу.
- На вкладке **Загрузить / Сохранить** выберите **Сохранить как шаблон…**, чтобы сохранить текущий поиск (шаблоны и параметры) и снова выбрать его позже из списка шаблонов.

## Сочетания клавиш

| Действие | Сочетание |
| --- | --- |
| Открыть «Найти файлы» | Cmd+Shift+F или Option+F7 |
| Начать / остановить поиск | Кнопка «Старт» в окне |
| Просмотреть выбранный результат | F3 |

## Примечания

- Поиск по содержимому читает файлы целиком для локальных папок; в других местах очень большие файлы пропускаются (примерно 16 МБ или 64 МБ при использовании регулярного выражения).
- Поиск внутри архивов спускается до четырёх уровней вложенных архивов.
- **Включать папки в результаты** также перечисляет папки, чьи имена совпадают, а не только файлы.
- Spotlight охватывает только проиндексированные локальные папки; для сетевых мест или сопоставления по шаблону оставьте его выключенным и позвольте «Найти файлы» сканировать.
