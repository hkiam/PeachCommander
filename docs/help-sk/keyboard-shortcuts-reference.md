Peach Commander je postavený pre klávesnicu: takmer všetko, čo robíte myšou, má kláves. Táto stránka zoskupuje predvolené skratky podľa úlohy, takže tú, ktorú potrebujete, nájdete na prvý pohľad. Klávesy zobrazené tu sú z predvolenej schémy **TC Classic** (tej, ktorú očakávajú dlhoroční používatelia Total Commanderu). Ak preferujete klávesy v štýle Mac, prepnite na schému **macOS Native** v ponuke Konfigurácia, kde sa tie isté akcie presunú na kombinácie s klávesom Command (napríklad Cmd+C na kopírovanie, Cmd+F na hľadanie). Môžete tiež prepísať ktorýkoľvek jednotlivý kláves.

## Funkčné klávesy

Mnoho základných akcií sídli na funkčných klávesoch. Ak stlačenie F5 zmení hlasitosť namiesto kopírovania, zapnite „Používať klávesy F1, F2 atď. ako štandardné funkčné klávesy" v Systémových nastaveniach, alebo podržte Fn počas stláčania klávesu.

| Kláves | Akcia |
|---|---|
| F1 | Otvoriť Pomocníka |
| F2 | Obnoviť aktívny panel |
| F3 | Zobraziť súbor pod kurzorom |
| F4 | Upraviť súbor pod kurzorom |
| F5 | Skopírovať výber do druhého panela |
| F6 | Presunúť alebo premenovať do druhého panela |
| F7 | Vytvoriť nový priečinok |
| F8 alebo Delete | Odstrániť (presunúť do Koša) |
| Shift+F5 | Kopírovať v tom istom priečinku |
| Shift+F6 | Premenovať na mieste |
| Shift+F8 | Odstrániť natrvalo (preskočiť Kôš) |

## Navigácia

| Kláves | Akcia |
|---|---|
| Tab | Prepnúť aktívny panel |
| Enter | Otvoriť priečinok, archív alebo súbor pod kurzorom |
| Backspace | Prejsť do nadradeného priečinka |
| Ctrl+PageUp | Prejsť do nadradeného priečinka |
| Ctrl+PageDown | Otvoriť priečinok alebo archív pod kurzorom |
| Alt+Vľavo / Alt+Vpravo | Späť / vpred v histórii |
| Alt+Nadol | Zobraziť zoznam histórie |
| Ctrl+\ | Prejsť na koreň zväzku |
| Ctrl+D | Otvoriť obľúbené (zoznam rýchleho prístupu) |

## Výber

| Kláves | Akcia |
|---|---|
| Insert | Prepnúť výber a ísť nadol |
| Medzerník | Prepnúť výber (a vypočítať veľkosť priečinka) |
| Num + | Vybrať podľa masky |
| Num - | Zrušiť výber podľa masky |
| Num * | Invertovať výber |
| Ctrl+Num + / Ctrl+Num - | Vybrať všetko / nevybrať nič |
| Ctrl+A | Vybrať všetko |
| Alt+Num + | Vybrať všetky súbory s rovnakou príponou |
| Num / | Obnoviť predchádzajúci výber |

| Kláves | Akcia |
|---|---|
| F5 | Kopírovať |
| F6 | Presunúť alebo premenovať |

| F8 / Delete | Odstrániť do Koša |
| Ctrl+M | Nástroj hromadného premenovania |
| Ctrl+C / Ctrl+X / Ctrl+V | Kopírovať / vystrihnúť / vložiť súbory |

|---|---|
| Ctrl+F1 | Stručné zobrazenie |
| Ctrl+F2 | Úplné (podrobnosti) zobrazenie |
| Ctrl+Shift+F1 | Zobrazenie miniatúr |

| Ctrl+F3 / F4 / F5 / F6 | Zoradiť podľa názvu / prípony / veľkosti / dátumu |

| Ctrl+Q | Prepnúť panel Rýchleho zobrazenia |

## Hľadanie

| Kláves | Akcia |
|---|---|
| Alt+F7 | Nájsť súbory |
| Ctrl+S | Rýchly filter (zúžiť viditeľné súbory) |
| Ctrl+B | Vetvové zobrazenie (splošťiť všetky podpriečinky) |

## Sieť

| Kláves | Akcia |
|---|---|
| Ctrl+F | Otvoriť správcu pripojení |
| Ctrl+N | Nové pripojenie |
| Ctrl+Shift+F | Odpojiť |

## Karty

| Kláves | Akcia |
|---|---|
| Ctrl+T | Nová karta |
| Ctrl+Shift+T | Nová karta na pozadí |
| Ctrl+W alebo Ctrl+F4 | Zatvoriť aktuálnu kartu |
| Ctrl+Shift+W | Zatvoriť všetky karty |
| Ctrl+Tab / Ctrl+Shift+Tab | Ďalšia / predchádzajúca karta |

## Poznámky

- Niekoľko klávesov TC Classic koliduje so systémovými skratkami macOS. Ctrl+Vľavo, Ctrl+Vpravo, Ctrl+Nahor a Ctrl+Nadol používa Mission Control a Spaces; ak v Peach Commanderi nefungujú, upravte ich v Systémových nastaveniach alebo ich premapujte v ponuke Konfigurácia.
- Schéma macOS Native presúva bežné akcie na kláves Command, pričom akcie funkčných klávesov zostávajú rovnaké. Prepnite schému, alebo zmeňte ktorýkoľvek jednotlivý kláves, z ponuky Konfigurácia.
- Stlačte Esc na zrušenie dialógu, vymazanie príkazového riadka alebo zatvorenie panela Rýchleho zobrazenia.
