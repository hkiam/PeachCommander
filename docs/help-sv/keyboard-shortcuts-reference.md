Peach Commander är byggt för tangentbordet: nästan allt du gör med musen har en tangent för sig. Den här sidan grupperar standardkortkommandona efter uppgift så att du kan hitta det du behöver med en blick. Tangenterna som visas här är standardschemat **TC Classic** (det som mångåriga Total Commander-användare förväntar sig). Om du föredrar Mac-liknande tangenter, byt till schemat **macOS Native** i Konfiguration-menyn, där samma åtgärder flyttas till Command-tangentkombinationer (till exempel Cmd+C för att kopiera, Cmd+F för att söka). Du kan även åsidosätta valfri enskild tangent.

## Funktionstangenter

Många grundläggande åtgärder finns på funktionstangenterna. Om ett tryck på F5 ändrar din volym istället för att kopiera, slå på "Använd F1-, F2- osv. tangenter som standardfunktionstangenter" i Systeminställningar, eller håll ned Fn medan du trycker på tangenten.

| Tangent | Åtgärd |
|---|---|
| F1 | Öppna hjälp |
| F2 | Uppdatera den aktiva panelen |
| F3 | Visa filen under markören |
| F4 | Redigera filen under markören |
| F5 | Kopiera urvalet till den andra panelen |
| F6 | Flytta eller byt namn till den andra panelen |
| F7 | Skapa en ny mapp |
| F8 eller Delete | Ta bort (flytta till papperskorgen) |
| Shift+F5 | Kopiera inom samma mapp |
| Shift+F6 | Byt namn på plats |
| Shift+F8 | Ta bort permanent (hoppa över papperskorgen) |

## Navigering

| Tangent | Åtgärd |
|---|---|
| Tab | Byt aktiv panel |
| Enter | Öppna mappen, arkivet eller filen under markören |
| Backspace | Gå till den överordnade mappen |
| Ctrl+PageUp | Gå till den överordnade mappen |
| Ctrl+PageDown | Öppna mappen eller arkivet under markören |
| Alt+Left / Alt+Right | Gå bakåt / framåt i historiken |
| Alt+Down | Visa historiklistan |
| Ctrl+\ | Gå till volymens rot |
| Ctrl+D | Öppna favoriterna (katalogsnabblistan) |

## Markering

| Tangent | Åtgärd |
|---|---|
| Insert | Växla markering och flytta nedåt |
| Space | Växla markering (och beräkna mappstorlek) |
| Num + | Markera via mask |
| Num - | Avmarkera via mask |
| Num * | Invertera markeringen |
| Ctrl+Num + / Ctrl+Num - | Markera alla / avmarkera alla |
| Ctrl+A | Markera alla |
| Alt+Num + | Markera alla filer med samma filtillägg |
| Num / | Återställ den föregående markeringen |

## Anteckningar

- Ett fåtal TC Classic-tangenter krockar med macOS systemkortkommandon. Ctrl+Left, Ctrl+Right, Ctrl+Up och Ctrl+Down används av Mission Control och Spaces; om de inte fungerar i Peach Commander, justera dem i Systeminställningar eller mappa om dem i Konfiguration-menyn.
- Schemat macOS Native flyttar vanliga åtgärder till Command-tangenten samtidigt som funktionstangentsåtgärderna behålls desamma. Byt schema, eller ändra valfri enskild tangent, från Konfiguration-menyn.
- Tryck på Esc för att avbryta en dialog, rensa kommandoraden, eller stänga Quick View-panelen.
