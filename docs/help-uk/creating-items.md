Коли ви впорядковуєте файли, вам часто потрібне нове місце, куди їх покласти, або свіжий документ, з якого почати. Peach Commander дає змогу створити нову теку або новий текстовий файл безпосередньо в панелі, у якій ви працюєте, без переходу до Finder. Нові елементи створюються в теці, що наразі показана в активній панелі.

## Створення нової теки

1. Клацніть панель, де має з'явитися нова тека, щоб вона стала активною панеллю.
2. Натисніть F7.
3. Введіть назву в полі, що з'явиться.
4. Натисніть Return (або клацніть OK). Нова тека з'являється в панелі, готова до використання.

Ви можете зробити більше, ніж створити одну теку за один крок:

- **Вкладені теки за один раз.** Введіть шлях зі скісними рисками, як-от `a/b/c`, щоб створити теку `a`, що містить `b`, що містить `c`. Будь-які рівні, яких ще не існує, створюються за вас.
- **Кілька тек одразу.** Розділіть назви вертикальною рискою, як-от `d1|d2`, щоб створити і `d1`, і `d2` поруч. Ви можете поєднати обидва стилі, наприклад `reports/2026|archive`.

## Створення нового текстового файлу

1. Клацніть панель, де має з'явитися новий файл.
2. Натисніть Shift+F4.
3. Введіть назву файлу, включно з його розширенням (наприклад, `notes.txt`).
4. Натисніть Return. Порожній файл створюється й відкривається у вашому редакторі, тож ви можете одразу почати друкувати.

Файл відкривається в тому редакторі, який Peach Commander налаштований використовувати для такого типу файлів. Див. **Відкриття та перегляд файлів** про те, як працює редагування.

## Комбінації клавіш

| Дія | Клавіші |
| --- | --- |
| Нова тека | F7 |
| Новий текстовий файл | Shift+F4 |

## Примітки

- У macOS назва теки чи файлу може містити майже будь-який символ. Лише скісна риска `/` (яка використовується як роздільник шляху для вкладених тек) і кілька зарезервованих символів не дозволені в одній назві.
- Використання двокрапки `:` у назві можливе, але може виглядати заплутано у Finder, тож його краще уникати.
- Якщо тека з такою самою назвою вже існує, Peach Commander просто залишає наявну — нічого не перезаписується.
