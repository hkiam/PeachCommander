Плагін Git показує стан репозиторію Git прямо в панелі файлів — без окремого застосунку, без термінала. Він додає два стовпці, що показують стан кожного файлу в робочому дереві та поточну гілку, підменю **Git** для щоденних команд (стан, індексування, коміт, pull, push), і використовує `git`, уже встановлений на вашому Mac. Це плагін, тож ви можете вимкнути чи вилучити його в **Конфігурація ▸ Плагіни…**.

## Що він додає

- **Два стовпці списку файлів** — *Git Status* і *Branch*. У репозиторії кожен файл показує коротке слово стану (Modified, Added, Deleted, Untracked, Renamed, Copied, Conflict, Ignored чи Changed), а панель показує поточну гілку. Увімкніть ці стовпці в **Конфігурація ▸ Стовпці…** (див. [Режими вигляду та сортування](view-modes-and-sorting.md)).
- **Меню Git** — під **Команди ▸ Git** і в контекстному меню файлу, з пунктами: **Git Status…**, **Git Add (stage)**, **Git Commit…**, **Git Pull** і **Git Push**.

*(Малюнок: Git Status повідомляє гілку та кожну зміну в робочому дереві.)*

## Перевірка стану

1. Поставте курсор на файл чи теку всередині репозиторію Git.
2. Виберіть **Команди ▸ Git ▸ Git Status…** (або клацніть правою кнопкою ▸ **Git ▸ Git Status…**).
3. З'являється зведення: поточна гілка (або *(detached)*), а потім або *Working tree clean.*, або список змін, кожен рядок якого показує стан і шлях до файлу.

Якщо курсор не всередині репозиторію, плагін просто каже *Not a Git repository.*

## Індексування, коміт, pull, push

- **Git Add (stage)** індексує файл під курсором (`git add`).
- **Git Commit…** запитує повідомлення коміту, а потім комітить усі зміни (`git commit -a`). Показується об'єднаний вивід, тож ви бачите, що саме сталося.
- **Git Pull** виконує pull лише з перемотуванням уперед (`git pull --ff-only`).
- **Git Push** надсилає поточну гілку (`git push`).

Після команди, що змінює репозиторій, активна панель оновлюється, тож стовпці стану лишаються актуальними.

## Примітки

- Плагін використовує системний Git за адресою `/usr/bin/git`. Якщо Git не встановлено, команди повідомляють, що Git недоступний. (Його надає встановлення Xcode Command Line Tools.)
- Стан репозиторію читається один раз на теку та кешується, тож прокручування великого репозиторію лишається швидким; кеш оновлюється після будь-якої команди, що змінює дерево.
- Коміт використовує `git commit -a`, який комітить відстежувані зміни; зовсім нові файли все ще потрібно спершу **Git Add (stage)**.
- Заголовки стовпців *Git Status* і *Branch* наразі показуються англійською навіть в інших мовах інтерфейсу; значення та діалоги локалізовані.
