Peach Commander побудований для клавіатури: майже все, що ви робите мишею, має клавішу. Ця сторінка групує типові скорочення за завданням, тож ви можете знайти потрібне з першого погляду. Клавіші, показані тут, — зі схеми за замовчуванням **TC Classic** (тієї, що очікують багаторічні користувачі Total Commander). Якщо ви віддаєте перевагу клавішам у стилі Mac, перемкніться на схему **macOS Native** в меню Конфігурація, де ті самі дії переходять на комбінації з клавішею Command (наприклад, Cmd+C для копіювання, Cmd+F для пошуку). Ви також можете замінити будь-яку окрему клавішу.

## Функціональні клавіші

Багато основних дій розташовані на функціональних клавішах. Якщо натискання F5 змінює гучність замість копіювання, увімкніть «Використовувати клавіші F1, F2 тощо як стандартні функціональні клавіші» в Системних параметрах, або тримайте Fn під час натискання клавіші.

| Клавіша | Дія |
|---|---|
| F1 | Відкрити довідку |
| F2 | Оновити активну панель |
| F3 | Переглянути файл під курсором |
| F4 | Редагувати файл під курсором |
| F5 | Скопіювати вибір до другої панелі |
| F6 | Перемістити чи перейменувати до другої панелі |
| F7 | Створити нову теку |
| F8 чи Delete | Видалити (перемістити в Кошик) |
| Shift+F5 | Скопіювати в тій самій теці |
| Shift+F6 | Перейменувати на місці |
| Shift+F8 | Видалити остаточно (оминути Кошик) |

| Клавіша | Дія |
|---|---|
| Tab | Перемкнути активну панель |

| Ctrl+PageDown | Відкрити теку чи архів під курсором |
| Alt+Ліворуч / Alt+Праворуч | Назад / вперед в історії |
| Alt+Униз | Показати список історії |

| Ctrl+D | Відкрити обране (список швидкого доступу) |

| Insert | Перемкнути виділення та спуститися вниз |

| Num - | Зняти вибір за маскою |

| Клавіша | Дія |

## Примітки

- Кілька клавіш TC Classic конфліктують із системними скороченнями macOS. Ctrl+Ліворуч, Ctrl+Праворуч, Ctrl+Угору та Ctrl+Униз використовуються Mission Control і Spaces; якщо вони не працюють у Peach Commander, скоригуйте їх у Системних параметрах або переприв'яжіть їх у меню Конфігурація.
- Схема macOS Native переміщає поширені дії на клавішу Command, зберігаючи дії функціональних клавіш такими самими. Перемкніть схему, або змініть будь-яку окрему клавішу, з меню Конфігурація.
- Натисніть Esc, щоб скасувати діалог, очистити командний рядок чи закрити панель Швидкого перегляду.
