Плагін System Monitor виводить живий показ активності вашого Mac прямо в смузі заголовка вікна: невеликі чипи для процесора, пам'яті, диска, мережі та — де це підтримує обладнання — GPU, батареї й датчиків. Кожен чип оновлюється раз на секунду; клацніть один, щоб отримати спливне вікно з графіком історії та докладним розкладом. Це плагін, тож ви можете увімкнути, налаштувати чи вилучити його в **Конфігурація ▸ Плагіни…**.

## Чипи у смузі заголовка

Коли плагін увімкнено, у смузі заголовка розташований ряд компактних чипів. Кожен чип — це кольорова крапка, коротка позначка та живе значення (деякі з вбудованим спарклайном):

| Чип | Показує |
| --- | --- |
| **CPU** | Навантаження процесора, з деталізацією за ядрами |
| **RAM** | Використана / загальна пам'ять (плюс закріплена, стиснена, swap) |
| **HDD** | Місце завантажувального тому та пропускна здатність читання/запису |
| **Net** | Швидкість завантаження / вивантаження та підсумки |
| **GPU** · **Batt** · **Sens** | Використання GPU · заряд і стан батареї · швидкість вентиляторів і температури |

Клацніть чип, щоб відкрити спливне вікно з великим поточним значенням, спарклайном **ІСТОРІЯ**, списком ключ/значення **ДЕТАЛІ** та — для процесора — списком **НАВАНТАЖЕННЯ ЯДЕР** зі смугами за кожним ядром.

## Налаштування

Виберіть **Команди ▸ System Monitor…** (або відкрийте **Конфігурація ▸ Налаштування ▸ System Monitor**), щоб налаштувати показ:

- **Показувати системний монітор у смузі заголовка** — головне ввімкнення/вимкнення чипів.
- **Профіль** — набори *Мінімальний*, *Середній* чи *Максимальний*, що обирають розумний комплект модулів.
- **Таблиця модулів** — увімкніть чи вимкніть кожен модуль (CPU, GPU, RAM, HDD, Net, Batt, Sens), виберіть його колір і перетягніть рядки, щоб задати порядок їх появи в смузі заголовка. Модулі, про які ваше обладнання не може повідомити, показуються як *(n/a)*.

## Примітки

- Усе вимірюється, ніколи не підробляється: модулі, чиї дані обладнання не надає (часто GPU чи датчики на деяких Mac), лишаються недоступними, а не показують вигадані числа. Батарея недоступна на стаціонарних комп'ютерах.
- Вибірка виконується на фоновому таймері лише поки показ видимий і зберігає близько 30 хвилин історії для графіків.
- Ваш вибір модулів, кольори та порядок зберігаються разом із конфігурацією застосунку.
