AI 助手是一个可选、可移除的插件，帮助你用自然语言处理文件。它可以总结或解释文档、建议更合适的文件名、翻译或校对文本、将数据整理成表格，甚至整理文件夹——并且在先向你展示一份计划后，可以替你执行文件操作。它会在 Apple Intelligence 可用时于设备本地运行，你也可以将其指向某个云端模型。由于它是插件，你可以从 **配置 ▸ 插件…** 中将其停用或彻底移除。

## 打开助手

选择 **命令 ▸ AI Assistant**，即可在窗口右侧的停靠面板中显示助手。输入请求并按 Return；助手可以读取文件、查找信息，并在你确认后进行更改。

## 右键操作（AI ▸）

使用助手最快捷的方式是右键菜单中的 **AI ▸** 子菜单：

- **在文件上** —— 总结、解释、建议名称、翻译成英文、校对、检测任务和生成表格。
- **在面板背景上** —— 整理此文件夹和查找可能的重复文件。

每个 **AI ▸** 操作都会打开**各自带标题的聊天**（例如 *Summarize – report.txt*），因此不同任务会保持独立，而不会堆积到一段冗长的对话中。当你自己在输入框中输入内容时，该请求会延续当前聊天。

## 管理你的聊天

- 使用面板顶部的聊天切换器在多个对话之间移动。
- **Delete ▾** 菜单提供 **删除此聊天** 和 **删除所有聊天**，因此当列表变长时你可以一次性清空。关闭面板时，空的聊天会被自动清理。

## 更改会先经过确认

对于任何会修改文件的操作——移动、重命名、写入、删除——助手都会显示一份**计划并等待你的确认**后再执行。你可以在设置中提高助手的自主级别来更改此行为，或将其降低为只读，使其永不做出任何更改。

## 设置

打开 **配置 ▸ 设置 ▸ AI**，可在单个页面上配置助手：

- **首选模型** —— 自动（如已配置则用云端，否则用设备本地）、设备本地（Apple Intelligence）或云端。
- **云端端点、模型和 API 密钥** —— 用于使用兼容 OpenAI 的模型代替设备本地模型。密钥存储在 macOS 钥匙串中，绝不会存入你的配置文件。
- **助手自主级别** —— 只读、确认更改（默认）或自主。
- **自定义系统提示** —— 可选指令，用于塑造助手回复的方式。
- **MCP 服务器** —— 一个可选的仅本地服务器，允许外部代理驱动此应用；默认关闭，可用令牌加以保护。

## 隐私

- 使用 Apple Intelligence 时，助手在**你的 Mac 上**运行；没有任何内容离开设备。
- 只有在**你配置了云端模型时**才会使用它，其 API 密钥保存在钥匙串中。
- 除非你有意提高自主级别，否则修改文件的操作都会在运行前经过确认。
