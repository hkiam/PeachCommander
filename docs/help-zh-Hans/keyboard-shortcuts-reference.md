Peach Commander 为键盘而生：你用鼠标做的几乎每件事都有对应的按键。本页按任务对默认快捷键进行分组，以便你一眼就能找到所需的那一个。此处显示的按键是默认的 **TC Classic** 方案（长期使用 Total Commander 的用户所熟悉的那套）。如果你偏好 Mac 风格的按键，请在“配置”菜单中切换到 **macOS Native** 方案，在那里相同的操作会移到 Command 组合键上（例如用 Cmd+C 复制、用 Cmd+F 搜索）。你也可以覆盖任何单个按键。

## 功能键

许多核心操作都位于功能键上。如果按 F5 改变的是你的音量而不是复制，请在“系统设置”中打开“将 F1、F2 等键用作标准功能键”，或在按键时按住 Fn。

| 按键 | 操作 |
|---|---|
| F1 | 打开帮助 |
| F2 | 刷新活动面板 |
| F3 | 查看光标下的文件 |
| F4 | 编辑光标下的文件 |
| F5 | 将选中内容复制到另一个面板 |
| F6 | 移动或重命名到另一个面板 |
| F7 | 创建新文件夹 |
| F8 或 Delete | 删除（移到废纸篓） |
| Shift+F5 | 在同一文件夹内复制 |
| Shift+F6 | 就地重命名 |
| Shift+F8 | 永久删除（跳过废纸篓） |

## 导航

| 按键 | 操作 |
|---|---|
| Tab | 切换活动面板 |
| Enter | 打开光标下的文件夹、压缩包或文件 |
| Backspace | 转到上级文件夹 |
| Ctrl+PageUp | 转到上级文件夹 |
| Ctrl+PageDown | 打开光标下的文件夹或压缩包 |
| Alt+Left / Alt+Right | 在历史中后退 / 前进 |
| Alt+Down | 显示历史列表 |
| Ctrl+\ | 转到卷的根目录 |
| Ctrl+D | 打开收藏夹（目录热门列表） |

## 选择

| 按键 | 操作 |
|---|---|
| Insert | 切换选择并向下移动 |
| Space | 切换选择（并计算文件夹大小） |
| Num + | 按掩码选择 |
| Num - | 按掩码取消选择 |
| Num * | 反转选择 |
| Ctrl+Num + / Ctrl+Num - | 全选 / 全不选 |
| Ctrl+A | 全选 |
| Alt+Num + | 选择所有相同扩展名的文件 |
| Num / | 恢复上一次的选择 |

## 文件操作

| 按键 | 操作 |
|---|---|
| F5 | 复制 |
| F6 | 移动或重命名 |
| F7 | 新建文件夹 |
| F8 / Delete | 删除到废纸篓 |
| Ctrl+M | 多重命名工具 |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制 / 剪切 / 粘贴文件 |
| Ctrl+L | 计算所选内容的大小 |
| Alt+Enter | 显示信息和属性 |

## 视图

| 按键 | 操作 |
|---|---|
| Ctrl+F1 | 简要视图 |
| Ctrl+F2 | 完整（详细）视图 |
| Ctrl+Shift+F1 | 缩略图视图 |
| Ctrl+F8 | 面板中的树状视图 |
| Ctrl+F3 / F4 / F5 / F6 | 按名称 / 扩展名 / 大小 / 日期排序 |
| Ctrl+H | 显示或隐藏隐藏文件 |
| Ctrl+Q | 切换 Quick View 面板 |

## 搜索

| 按键 | 操作 |
|---|---|
| Alt+F7 | 查找文件 |
| Ctrl+S | 快速过滤（缩小可见文件的范围） |
| Ctrl+B | 分支视图（展平所有子文件夹） |

## 网络

| 按键 | 操作 |
|---|---|
| Ctrl+F | 打开连接管理器 |
| Ctrl+N | 新建连接 |
| Ctrl+Shift+F | 断开连接 |

## 标签页

| 按键 | 操作 |
|---|---|
| Ctrl+T | 新建标签页 |
| Ctrl+Shift+T | 在后台新建标签页 |
| Ctrl+W 或 Ctrl+F4 | 关闭当前标签页 |
| Ctrl+Shift+W | 关闭所有标签页 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个标签页 |

## 说明

- 少数 TC Classic 按键与 macOS 系统快捷键冲突。Ctrl+Left、Ctrl+Right、Ctrl+Up 和 Ctrl+Down 被“调度中心”和“空间”使用；如果它们在 Peach Commander 中不起作用，请在“系统设置”中调整它们，或在“配置”菜单中重新映射它们。
- macOS Native 方案将常用操作移到 Command 键上，同时保持功能键操作不变。可从“配置”菜单切换方案，或更改任何单个按键。
- 按 Esc 可取消对话框、清除命令行，或关闭 Quick View 面板。
