每个面板都能以标签页的形式同时容纳多个文件夹，这样你常用的位置只需一次点按即可到达，而不必来回导航。标签页属于单个面板：左右面板各自保有自己的标签页行，切换或关闭标签页只影响活动面板。文件列表上方会出现一个小标签栏，为每个打开的标签页显示一个标签片，并在末尾附上一个“+”按钮。

## 使用标签页

1. 点按面板使其活动。新标签页总是在活动面板中打开。
2. 选择 显示 > 新建标签页，或按 Cmd+T，在当前文件夹上打开一个新标签页。你也可以点按标签栏末尾的“+”按钮。
3. 点按任意标签片以切换，或按 Cmd+} 到下一个标签页、Cmd+{ 到上一个。
4. 要关闭当前标签页，选择 显示 > 关闭标签页 或按 Cmd+W。你也可以用中键点按标签片来关闭它。选择 显示 > 关闭全部标签页 可清除除当前之外的所有标签页。

## 在新标签页中打开文件夹

1. 将光标移到文件列表中的某个文件夹。
2. 选择 显示 > 在新标签页中打开文件夹（Cmd+Shift+T），在同一面板的新标签页中打开该文件夹。
3. 要在不离开当前标签页的情况下打开标签页，选择 显示 > 在后台新建标签页。

## 锁定标签页

锁定标签页会将其固定到所在文件夹。选择该标签页，然后选择 显示 > 锁定标签页。标签片上会出现一个小锁图标。标签页被锁定时，导航进入另一个文件夹会在新标签页中打开该文件夹，而不改变被锁定的标签页，因此你固定的位置保持不变。再次选择该菜单项即可解锁。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 新建标签页 | Cmd+T |
| 在后台新建标签页 | 显示 > 在后台新建标签页 |
| 在新标签页中打开光标下的文件夹 | Cmd+Shift+T |
| 关闭当前标签页 | Cmd+W |
| 下一个标签页 | Cmd+} |
| 上一个标签页 | Cmd+{ |
| 锁定 / 解锁标签页 | 显示 > 锁定标签页 |

## 提示

- 右键点按标签片可使用快捷操作，例如复制或关闭该标签页。
- 标签页是按面板划分的。用它们把一个工作文件夹和一个目标文件夹并排放置，然后在两者之间切换而不丢失位置。
- 锁定对于你经常返回的文件夹很方便：你可以浏览到别处，仍能在其标签页上找到它，原封不动。
