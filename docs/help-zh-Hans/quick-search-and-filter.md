当文件夹里有数百个项目时，你很少需要滚动。Peach Commander 让你通过键入名称直接跳到某个文件（快速搜索），把列表缩减到只剩你关心的项目（快速筛选），并显示或隐藏 macOS 通常藏起来的点文件。这三者都在活动面板内工作，无需打开对话框。

## 通过键入跳到文件（快速搜索）

1. 点按文件面板使其活动。
2. 开始键入名称的开头。光标会跳到第一个匹配项。
3. 继续键入以细化匹配，或再次按同一个字母以在以该字母开头的项目间循环。
4. 键入的文本在短暂停顿后清除，因此你随时可以开始新的搜索。

默认情况下，普通字母会进入命令行，快速搜索由 Ctrl+Option+字母 触发（经典行为）。你可以在“设置”中改为让快速搜索响应普通键入，或将其关闭。

## 筛选列表（快速筛选）

1. 在活动面板中按 Ctrl+S 打开快速筛选。
2. 键入筛选掩码。面板会随你键入实时缩窄到匹配项。
3. 按 Esc 清除筛选并重新显示全部。

筛选接受多种掩码：

- **纯文本** 匹配名称中任意位置包含所键入内容的项（例如 `report` 会显示名称中任意位置含有“report”的每个项目）。
- **通配符** 使用 `*`（任意字符）和 `?`（一个字符）。用分号分隔多个掩码，并在竖线后添加排除项，例如 `*.jpg;*.png|*thumb*` 显示图像但隐藏缩略图。
- **Finder 标签** 按标签颜色筛选：键入 `tag:red`（或 `#red`）只显示红色标签的项，或仅键入 `tag:` 显示带任意标签的所有项。

## 显示隐藏文件

按 Ctrl+H，或从“显示”菜单选择相应命令，以切换隐藏项（以点开头的名称和系统隐藏文件）。此设置应用于活动面板，并在会话间记住。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 快速搜索（经典模式） | Ctrl+Option+字母 |
| 快速筛选开/关 | Ctrl+S |
| 清除筛选 / 取消 | Esc |
| 显示/隐藏隐藏文件 | Ctrl+H |

## 备注

- 快速搜索只移动光标；快速筛选则实际改变所列出的项目。当你想对子集进行操作（例如只选择或复制匹配项）时使用筛选。
- 筛选和隐藏文件设置是按面板的，因此两侧可以同时显示不同内容。
- 快速搜索从名称开头匹配；快速筛选的纯文本模式则在名称任意位置匹配。若希望筛选也如此，请使用像 `*text*` 这样的通配符。
