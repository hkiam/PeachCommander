# I01 — Scaffold & Dual-Pane Window (read-only)

**Goal / Demo:** `Tools/build.sh` produces PeachCommander.app; launching shows a
TC-style window: two panels listing the real home directory (Name/Ext/Size/Date/
Attr columns, `..` entry, dirs first), function-key bar, Tab switches the active
panel, Enter/Backspace navigate. Read-only, no selection yet.

**Prerequisites:** none. **Read first:** CONVENTIONS.md, docs/architecture/
tech-stack.md, architecture.md, docs/product/ui-reference.md, SPEC-001, SPEC-002 §1-2.
