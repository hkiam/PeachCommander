# I04 — File Operations Engine (F5/F6/F7/F8)

**Goal / Demo:** Copy a 10 GB folder with live progress while still browsing;
move, mkdir (nested), delete to Trash; overwrite dialog with all TC buttons;
pause/resume/cancel; background queue with Transfer Manager window; F4 edit.
The app becomes genuinely useful here.

**Prerequisites:** I03. **Read first:** SPEC-004 (whole), performance.md
(operation rules). This is the most safety-critical iteration: all destructive
tests ONLY on temp fixtures.
