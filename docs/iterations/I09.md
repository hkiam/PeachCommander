# I09 — Archives as Directories

**Goal / Demo:** Enter a .zip like a folder, F3 a file inside it, F5 files out of
and INTO it, Alt+F5 pack selection to zip/tar.gz, Alt+F9 unpack, nested archives,
passworded zips. TC's signature feature.

**Prerequisites:** I08. **Read first:** SPEC-007 (whole), ADR-005.
