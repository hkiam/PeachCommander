# I14 — Plugin Host & Packer Plugins (PCX)

**Goal / Demo:** Install `SamplePacker.pcxplugin` via the plugin manager, then
browse/pack/unpack its `.pak` format exactly like zip. SDK headers + porting
guide exist. First plugin type proves the host.

**Prerequisites:** I13. **Read first:** SPEC-012 §1-§2, §6-§9, ADR-004.
Fetch WCX SDK reference (https://ghisler.github.io/WCX-SDK/) for signature
details when writing headers.
