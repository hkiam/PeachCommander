# I15 — File System Plugins (PFX) & FTP/SFTP

**Goal / Demo:** "Network" root in the drive list; connect to an SFTP server and
an FTP server, browse, copy both ways with progress/resume, sync a folder with a
remote. All through the public PFX API (ADR-011).

**Prerequisites:** I14. **Read first:** SPEC-012 §4, SPEC-011 (whole).
Fetch WFX SDK (https://ghisler.github.io/WFX-SDK/) when writing pfx.h.
Mini-ADR required in T04: libssh2 packaging choice.

## Progress (2026-07-23)

A working, tested **built-in FTP client** now lives in a new `PCNet` module
(+ a `SecretStore` in PCFoundation). The boxes below stay unchecked only where a
full AC (SFTP, TLS, the connection-manager UI, transfer integration) is not yet
met; the FTP data path itself is implemented and verified.

- **Listing parsers** (`FTPListParser`): MLSD / UNIX / DOS + auto-detect →
  `RemoteFileEntry`; golden tests. *(T03)*
- **Control-reply + PASV/EPSV parsing** (`FTPReplyParser`, `FTPDataAddress`):
  RFC 959 framing + passive-address decode; canned-dialog tests. *(T03)*
- **Command choreography** (`FTPControlConnection` over an `FTPControlTransport`
  seam): login, PWD/CWD, EPSV→PASV data, LIST, RETR, STOR, DELE/MKD/RMD,
  RNFR+RNTO, SIZE — unit-tested against a scripted canned-dialog transport. *(T03)*
- **Live transport** (`NWFTPControlTransport`/`NWFTPDataTransport`,
  Network.framework): real TCP; verified end-to-end by an in-process NWListener
  loopback server (opt-in `TEST_RUNNER_PC_FTP_LOOPBACK=1`). *(T03)*
- **VFS adapter** (`FTPFileSystem: VirtualFileSystem`, read/write/rename): list/
  stat/openRead/openWrite/mkdir/delete/rename/localFile, FTP→VFSError mapping;
  tested via the scripted transport. *(T01 for FTP)*
- **Site model** (`FtpSite`/`FtpSitesFile`/`FtpURL`) + **secrets**
  (`SecretStore` Keychain+mock, `FtpCredentials`). *(T05 model, T02/§6)*
- **Quick-connect wired into the app**: Net > FTP New Connection… / Ctrl+N /
  cm_NetConnect → URL prompt → secure password prompt → connect → mount the
  FTPFileSystem in the active panel (`PanelController.enterNetwork`). *(T05, F-211)*
- **Implicit FTPS (TLS)**: `useTLS` transport + PBSZ 0/PROT P protected data
  channel; `ftpsi://` maps to it. *(T03)*

- **MLSD-preferred listing**: FEAT detection → list() uses MLSD when the server
  advertises MLST, else LIST. *(T03)*

Remaining: explicit FTPS (AUTH TLS — blocked: NWConnection has no STARTTLS
upgrade; would need a BSD-socket/NIO transport) + proxies +
keep-alive/reconnect (T03 polish); `pfx.h` + generic PFX plugin host (T01, for
third-party FS plugins); SFTP/libssh2 (T04, needs a vendoring ADR); full
connection-manager UI with saved sites + Ctrl+F (T05 UI); transfer integration/
resume/bandwidth (T06). Live FTP(S) paths are best verified against a real or
dockerized server (`Tools/dev-servers.sh`).
