# I16 — Lister Plugins (PLX) & Content Plugins (PDX)

**Goal / Demo:** A plugin renders CSVs as a table in Lister/Quick View; a content
plugin adds "Image width/height" columns, searchable in Alt+F7 and usable in
multi-rename `[=...]`. Custom column sets UI. Plugin system complete.

**Prerequisites:** I15. **Read first:** SPEC-012 §3,§5, SPEC-002 §3 custom
columns. Fetch WLX/WDX SDKs (ghisler.github.io) for signature details.
