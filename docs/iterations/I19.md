      the file was read as strict UTF-8 (a TC `.mnu` is ANSI or UTF-16 → decode failed →

      usercmd.ini/wincmd.ini), parser diagnostics per skipped line, and greyed-out entries
      for unknown commands. Numeric TC ids still resolve only where a 1:1 command exists,
      and accelerator hints in captions stay ignored by design (the keymap is the single
      source for shortcuts) — both recorded on the F-257 row.
